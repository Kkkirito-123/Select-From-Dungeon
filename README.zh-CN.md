# SQL 魔王城 · SELECT * FROM DUNGEON

**简体中文** | [English](README.md)

一个面向 SQL 初学者与面试复习者的浏览器肉鸽。SQL 就是战斗动作：探索由种子生成的像素魔王城，
实际走过连续迷宫，进入有名字怪物所在格后切换到独立对战，写出一条完整 SQLite 查询，再把
正确结果变成攻击动画。

## MVP 现在能玩什么

- 完成一个由两张 64×48 连续迷宫组成的 Run。每层在技术上分成十二块 16×16 区域，并用额外
  环路减少死路折返；第一层是石砌魔王城，第二层换成深蓝、电青与紫色的“雷鸣奏鸣塔”。
- 击败第一层魔王并拾取钥匙后，双表连接传送门自动播放约 1.2 秒并进入第二层，不需要再次寻路、
  按 `E` 或选择菜单。等级、XP、武器、遗物和查询数跨层保留。
- 实际行走会揭开战争迷雾并让发现式小地图显形。小地图只记录已探索区域与课程门锁，不能点击，
  也不会传送玩家。
- 移动进入存活必修怪物所在格，或触发按步数判定的伏击后，自动进入类似宝可梦的单体战斗。
  开局和战后都有安全步数，长时间未遇敌时会保底遭遇，刷新页面不能重抽。地图普通怪约每
  1,100 毫秒巡逻一步，魔王固定不动。每次查询前都能看到对手完整名字、ID、血量和下一次反击。
- 按 `Q + S` 或触控按钮打开游戏内终端。每个阶段都从空编辑器开始，玩家需要完整写出
  `SELECT ... FROM ...`，不是补最后一个空。
- 无需离开游戏即可使用内置 `PLAN ASSIST` 补全栈。输入前缀会排序提示 SQL 关键词、函数、
  当前可见表名与字段名，`m.` 等别名会把范围缩到对应表；支持方向键配合 `Enter`/`Tab`、点击、
  触控，以及 `Ctrl/Command + Space` 主动唤起。接受建议不会执行查询，也不会填完整答案。
- 真实执行浏览器内 SQLite WASM，可查看结果表与 `EXPLAIN QUERY PLAN`。正确结果发动攻击；错误
  结果或语法错误触发已预告的怪物反击；空输入不消耗回合。
- 站在任意一层的锁定 Boss 门旁按 `E`，可尝试可选高难 `QUERY BREACH` 机关。完成固定组合查询
  可以提前打开当前物理门，但不增加课程掌握、XP 或战利品；错误结果或语法错误损失一颗心，
  空输入和安全退出没有代价。
- 每局以两颗心开始。击败普通、精英、魔王分别获得 1、3、5 经验；累计经验达到 2、4、6、8，
  此后每 4 XP 一档直到 24 时升级，每升一级增加一颗生命上限并恢复一颗心。
- 走上松散怪物掉落即可自动拾取；祭坛、宝箱和篝火使用 `E` 调查。固定课程武器仍确定可得：
  `SELECT` 后掉落过滤弓，`IS NULL` 后掉落空值提灯，进入 `GROUP BY` 前必得聚合战锤；第二层
  会继续获得雷序军刀与关系链刃。每次获得道具都会弹出不阻塞操作的说明卡，显示名称、描述和
  准确效果。
- 运行时用 Web Audio 播放电子古典音乐：第一层随机轮换四首原创抒情曲式，第二层随机轮换三首
  由代码重新编排与合成的公版贝多芬芯片曲。战斗切换为原创激昂太空街机曲；不打包第三方录音，
  也不复制其他游戏旋律。移动、撞墙、遭遇、查询施法、命中、受伤、
  阶段完成、掉落、拾取、知识门开启、胜利与失败都有不同提示。项目不打包第三方音乐或音效素材。
- 可选的逐步新手引导会依次教移动、寻找怪物、打开终端、执行第一次查询和拾取第一次掉落；可
  跳过或重新教学，不会改变 SQL 熟练度。
- 当前迷宫、演员、地面物品、迷雾与战斗状态和永久学习档案分开保存。开始新 Run 会重置局内
  状态，但保留已掌握知识、练习次数、通关数和最佳查询数。
- 桌面支持 WASD/方向键，窄屏提供可见方向键和全屏 SQL 终端，可直接嵌入博客页面操作。

## 第一层学习路线

1. `SELECT / FROM`：先查询怪物 `#101` 的 `name`，再查询它的 `weakness`。
2. `WHERE / AND`：用房间和状态锁定逃脱猎犬，再用屏幕上显示的怪物名字查询弱点。
3. `IS NULL`：找出没有主人的怪物 ID，再找出“无主人且被诅咒”的怪物名字。
4. `COUNT / GROUP BY`：把 `monster_id = 800` 的信号按 `channel` 分组，并把数量命名为 `total`。
5. `HAVING`：先用 `COUNT(*) >= 2` 过滤魔王 `#900` 的信号组，再把阈值提高到 `>= 3`，只留下
   最强核心。

`WHERE` 与 `IS NULL` 是自由顺序分支；两者掌握并领取固定聚合战锤后，才会解锁 `GROUP BY`。
种子可以改变物理迷宫和非关键奖励，但不会改变必修查询数据，也不会让关键武器随机缺失。课程
依赖图只负责知识门锁，不负责传送；已经解锁的区域以玩家实际探索顺序为准。

每个阶段都有入局说明、可见 Schema、知识锁和渐进提示。第一层语法范围是一条平坦 `SELECT`，
暂不允许 `OR`、子查询或集合运算；在这个范围内，判定同时检查“结果语义 + 当前 SQL 知识点”。
表别名和 `HAVING total ...` 可以通过，不要求照抄唯一字符串。

## 第二层学习路线

1. `ORDER BY / LIMIT`：先找出最高 `charge` 的信号，再按降序返回前两名。
2. `DISTINCT`：从重复镜像信号中只保留不同的 `channel`，并按名称排序。
3. `INNER JOIN / ON`：用 `monsters.room_id = rooms.id` 连接怪物与房间，读取房间名和区域。
4. `LEFT JOIN / IS NULL`：保留左表怪物，用右表空值找出没有装备记录的目标。
5. `JOIN` 综合魔王：先连接房间后分组、`HAVING` 过滤并排序，再连接装备表找出最强核心。

第二层题目仍要求玩家自己写完整语句，并同时校验真实结果、当前知识锁与真实连接关系；`ON 1=1`
配合硬编码过滤不能绕过课程。第二层怪物血量按课程阶段数与确定武器伤害校准，不会要求无意义地
重复同一道题。

## 本地运行

要求 Node.js `>=20.19` 与 pnpm `11.9.0`。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

打开 Vite 输出的地址，通常是 `http://localhost:5173/`。不要通过 `file://` 直接打开
`index.html`，SQLite WASM 必须通过 HTTP 加载。

第一只怪物的两次攻击是：

```sql
SELECT name
FROM monsters
WHERE id = 101;

SELECT weakness
FROM monsters
WHERE id = 101;
```

从魔王城入口出发，跟随新手引导卡或青色信标实际走过迷宫。小地图只显示已经探索的位置，不能
点击移动。进入投影史莱姆所在格 → 按 `Q + S` → 完整输入查询 → `Ctrl/Cmd + Enter` 执行
攻击。怪物倒下后，走到发光的松散掉落上自动拾取；`E` 只用于调查祭坛、宝箱和篝火。

## 架构与存档

```text
AppShell ── HUD、发现式小地图、新手引导、终端与查询证据
    │
GameSession ── 物理世界、演员、迷雾、战斗、掉落与档案的事实权威
  ├─ RunGraph ── 课程依赖与兴趣点门锁
  ├─ MazeGenerator/MazeFloor ── 64×48 种子物理迷宫
  ├─ MazeValidation ── 拓扑、可达性与存档不变量
  ├─ EncounterDirector ── 确定性安全期与按步数伏击
  ├─ MonsterRoaming ── 确定性的缓慢巡逻决策
  ├─ gateChallenges ── 可选 Boss 门查询特征与结果约束
  ├─ lessonEvaluator ── 结果语义 + 知识锁
  ├─ SqlAutocomplete ── 可见 Schema 补全与无障碍 Listbox 状态
  ├─ SqlEngine ── 只读 SQLite WASM 执行与四表教学 Schema
  ├─ DungeonScene ── 连续探索、迷雾、碰撞与巡逻
  ├─ BattleScene ── 独立对战呈现和攻击动画
  ├─ FeedbackDirector ── 探索通知与事件音频路由
  ├─ ArcadeAudio ── 随机探索音乐与原创战斗 Web Audio
  └─ OnboardingController ── 独立持久化的渐进引导
```

`RunGraph` 是课程依赖图，不负责移动玩家；`MazeFloor` 才是物理世界。发现式小地图只是只读的
探索视图，移动、同格遭遇、拾取与知识门都由 `GameSession` 对照迷宫进行判定。

迷宫生成器当前只隔离 `topology` 与 `decor` 两条随机流。Actor 与固定课程掉落从课程锚点确定性
派生；本 MVP 没有独立的 `theme`、`loot`、`spawn` 随机流，也没有单独的内容版本字段。

终端只接受一条 `SELECT`，最多显示 50 行；拒绝 DML、DDL、`PRAGMA`、`ATTACH` 和多语句。
查询计划与 I/O 热量是 SQLite 教学信号，不能当作 MySQL 优化器的真实证据。

浏览器本地存储拆成：

- `select-from-dungeon:run:v5`：可丢弃的当前 Run，包括当前楼层、生成迷宫、世界演员、地面物品、
  已发现迷雾格、生命、等级/经验、遭遇计量、装备、遗物和战斗进度。
  还包括已打开的挑战门与当前机关题。
- `select-from-dungeon:profile:v2`：十项已掌握课程、练习次数、通关数和最佳查询数。
- `select-from-dungeon:onboarding:v1`：可选引导是否已完成或跳过。

有效的 `run:v4` 会在内存中迁移为 v5，保留原进度并默认关闭所有挑战门；更早的 Run Key
不读取也不删除。有效的 `profile:v1` 会自动迁移到 v2，保留第一层学习档案并补齐第二层计数。
`src/main.ts` 对快照持久化进行防抖，避免每次移动或巡逻状态变化都同步写入一次本地存储。


`LICENSE` 与 `ATTRIBUTIONS.md` 自动复制进去；不要另外手工维护副本。把该目录部署到能正确
提供 WASM MIME 类型的静态托管即可。

扣一颗心、正确语义开门、实际穿过已打开门、刷新恢复、终端聚焦不引发页面跳动，以及 390×844
视口无横向溢出。最新补全验收还覆盖了自动前缀提示、`Ctrl+Space`、方向键选择、`Enter`、
`Tab`、指针/触控接受、两阶段 `Escape`、查询次数不变、控制台无警告/错误，以及桌面和
390×844 布局。此前还验证过页面启动、HUD、触控区、同格必修战斗、掉落拾取、巡逻接触、

检查。单元测试和构建通过不能替代这些浏览器验收。领域层自动化已经用真实移动判定覆盖
WHERE/IS NULL 两种分支顺序、自动换层和第二层五门课程，过程中不调用 Session 的传送或定位
辅助；它同样不能代替尚缺的完整浏览器手动通关。

## 范围与归属

当前 MVP 覆盖双层十组概念，最远到 `LEFT JOIN` 与多知识点综合 `JOIN`。子查询、窗口函数、
事务、索引原理、隔离级别和更完整的 MySQL 八股属于后续楼层，不是本版本已经覆盖的能力。
