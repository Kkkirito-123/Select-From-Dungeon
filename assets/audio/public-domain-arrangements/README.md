# F1 / F2 public-domain arrangements

This folder records the source and rights chain for the first two floors'
runtime music. The actual browser files live under `public/assets/audio/`.

- Composition layer: Mozart K.265 and Handel HWV 348–350 are public-domain
  works.
- Transcription layer: short themes were independently entered as declarative
  note data in `scripts/generate-runtime-classical-audio.mjs`.
- Arrangement/performance/recording layer: generated by this project.
- Third-party recording, MIDI, sample, SoundFont, impulse response, and score
  scan inputs: none.
- Runtime encodings: OGG first, project-generated MP3 fallback.

Run the generator from the repository root with:

```bash
node scripts/generate-runtime-classical-audio.mjs
```

The generated `audio-source.json` is the authoritative per-file hash and rights
record. The generator requires `ffmpeg` only to encode OGG and MP3; it performs
all synthesis itself.
