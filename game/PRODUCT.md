# Product

## Register

product

## Release Baseline

`v2.0.0` 在八层本地浏览器学习肉鸽上完成紧凑复合地图、角色显形、抄写员、《失名录》、
`MIGRATE` 主线和名字回收图鉴；当前 F1/F2 垂直切片使用项目基于公版主题生成并导出的连续
OGG / MP3，F3–8 保留轻量 Web Audio 配方。它不代表完整 SQL 方言、完整 MySQL/InnoDB 实现或在线服务。

## Platform

web

## Users

主要用户是正在入门 SQL、准备面试八股或希望通过短回合重复练习巩固语法的中文学习者。他们在桌面或手机浏览器中游玩，希望先探索、再在明确目标下写出完整 SQL，而不是阅读一页静态题库。博客读者是重要的次级入口，因此核心流程必须能在 iframe、无账号和本地存储受限的环境中继续运行。

## Product Purpose

把 SQL 查询变成一套可以观察、预测和复盘的战斗动作。玩家在由 Seed 生成、减少死路的像素魔王城中探索，通过地图怪物或按步数触发的伏击进入单体对战，根据游戏世界中的实体和状态写出完整只读 SQL，并从真实 SQLite 结果、查询计划、伤害和怪物反应中立即理解语句作用。成功意味着新手无需离开游戏即可完成“探索、遭遇、查询、获得经验、拾取并理解道具、自动跨层、继续探索”的闭环，并逐步完成八层共 47 组 SQL 课程。

## Positioning

这不是给 SQL 题套一层皮，而是让“查询结果”真正决定可见世界、攻击目标和战斗反馈的可探索 SQL 肉鸽。

## Brand Personality

像素魔王城、街机反馈、教学透明。氛围可以阴暗神秘，但操作提示、怪物身份、SQL 目标和结果证据必须清晰、直接、可信；打击感服务于学习反馈，不掩盖判题原因。

## Anti-references

- 不做必须按题号或怪物编号顺序点击的线性题库。
- 不把核心操作放到游戏画面之外的旁栏，也不让路线图代替实际探索。
- 不复制 Minecraft、宝可梦或其他游戏的代码、美术、音频、关卡文本和具体参数。
- 不用随机暴击或随机掉落阻断课程，让玩家无法解释同一条 SQL 为什么造成不同结果。
- 不用长篇模态教程一次塞完全部规则，也不以粒子、震屏和音效遮住错误原因与下一步提示。

## Design Principles

1. 世界先反馈，说明随后出现：触碰、命中、拾取和开门都必须先有即时画面与声音，再用短文案解释结果。
2. 随机空间，确定学习：Seed 可以改变迷宫、装饰、巡逻和非关键奖励，但不能改变必修数据、知识门或关键武器可获得性。
3. 探索自由，依赖透明：WHERE 与 IS NULL 等同级课程可自由选择；真正需要前置知识时，在世界中显示可理解的门锁。
4. 一次动作只给一个主反馈：一次移动、命中或拾取只触发一组语义一致的声音、动画和状态播报。
5. 证据可复盘：完整 SQL、结果集、查询计划、伤害数值和剩余生命始终可以核对。
6. 寻路不应压过学习：迷宫保留探索与空间记忆，但通过额外环路、遭遇安全期和长时间无战斗保底，把主要时间还给 SQL 回合。
7. Schema 必须随时可查：完整字段、类型、可空性与逻辑关系使用一份权威目录驱动，任务提示可以
   聚焦当前表，但不能让玩家因字段名缺失而离开游戏查资料。
8. Debug 不污染正式 Run：管理员全图、切层和区域定位只用于检查内容，任何预览快照都不能覆盖
   玩家最后一次正式存档。

## Current Run Rules

- 新 Run 以两颗心开始；错误结果或语法错误触发一次固定一颗心的预告反击。
- 普通、精英、魔王胜利分别获得 1、3、5 经验，累计经验在 2、4、6、8 时升级；升级增加一颗生命上限并恢复一颗心。
- 必修怪物承担课程推进，随机伏击提供当前已解锁概念的短练习；战后安全步数避免连续打断，长时间无战斗则保底遭遇。
- 必修怪物在击败前只暴露稳定 ID；最后一击回收直白名字并永久写入怪物图鉴。
- 战斗可主动撤退到最近复活点；生命、护甲和敌人剩余生命都保持当前值。
- 每层三生态区由两组实体区域门连接；区域门不绕过知识锁，中段区域首领击败后自动送入末段主线区。
- 可选随机掉落只保留低概率自动恢复品：普通 2%、小型精英 5%、区域首领 10%；固定课程奖励由对应房间宝箱承载。
- 每层 Boss 门旁都有一台可选高难 SQL 越级机关；正确的固定组合查询只打开该物理门，错误结果或
  语法错误扣一颗心，且不会增加课程掌握、练习次数、XP 或战利品。
- 第一至七层钥匙自动开启约 1.5 秒的传送过场，不要求再寻路或按键；跨层保留等级、XP、武器、
  防具、背包、遗物与查询数，并逐层提高课程、怪物、装备和地图难度。
- 掉落与调查奖励在获得时显示名称、世界观描述和准确效果，说明卡不得阻塞继续移动。
- 第一、二层使用项目自行生成的连续 OGG/MP3 母带，主题取自公版古典作品，探索 / 战斗 / Boss
  状态以 1.2 秒交叉淡化切换；第三至八层保留轻量 Web Audio 兼容乐谱，事件音效实时生成。
  项目不打包现代演奏录音、MIDI、采样库或其他游戏原声。
- 新 Run 使用 `48×36 / generator v5` 紧凑复合地图；旧 `64×48 / generator v4` 仅作为
  兼容存档继续加载。
- 抄写员、本层短叙事和《失名录》全部只依据本地进度与答案证据；唯一主线结局为
  `MIGRATE`，不接入 Agent、账号或网络记录。
- 页面隐藏时暂停渲染与音频并刷新本地进度；正常运行以 30 FPS 为目标，高频移动存档会合并，
  查询、战利品、背包和拓扑变化仍立即保存。

## Accessibility & Inclusion

Web 端同时支持键盘和触控；核心操作不依赖颜色、音频或 hover。保留 `prefers-reduced-motion`
降级、可静音和 Web Audio 不可用回退；终端提供明确焦点管理，SQL 建议使用可键盘操作的
Listbox，接受建议不会提交查询或生成完整答案；Schema 表标签支持方向键、`Home` 与 `End`，
关系不能只靠颜色表达。战斗结果只播报一次；移动端核心文字与触控目标保持可读可点。本项目
暂不宣称通过特定 WCAG 认证。`v1.0` 已检查键盘/触控、Reduced Motion、640px 回流代理和
390×844 布局；F1/F2 已补精确 320px 回流检查，专用屏幕阅读器流程和认证级对比度审计仍需
单独人工验收。
