## 1. 本次目标

把已经能运行八层 SQL 课程的 `v1.1.0`，升级成一款具有完整世界上升感、空间记忆和主线叙事的
浏览器像素肉鸽：

> 玩家从海中黑山的地下档案出发，用真实 SQL 调查怪物与世界记录，逐层确认自己是多次
> `ROLLBACK` 后留下的历史集合，最后在黑金高堂完成一次 `MIGRATE`。

MVP 2.0 必须同时做到：

1. 八层仍能从头到尾完成全部 47 组 SQL 学习；
2. 地图不再以大面积细路和寻路时长制造内容；
3. 每层拥有独立的地貌、交通、怪物族群、视觉和音乐；
4. 篝火、抄写员、失名录和层间演出形成一条完整但克制的主线；
5. 保留当前低性能消耗、离线运行、真 SQLite、确定性 Seed 和旧永久掌握进度。

## 6. 产品支柱

1. **查询改变理解**：正确 SQL 不只是扣血，还揭示怪物、区域或玩家身份的真实记录。
2. **空间可以掌握**：第一次走远路，第二次从背面打开捷径，第三次快速利用已理解的空间。
3. **玩家时间受尊重**：主线密度来自题目、战斗和发现，不来自重复赶路。
4. **同一座王城**：八层的高度、远景、材质和音乐共同证明玩家一直在向上。
5. **温暖有唯一来源**：抄写员和篝火提供稳定、安静、不过度解释的安全感。

反支柱：

- 不把地图做成无地标的算法迷宫；
- 不用随机关键掉落阻塞课程；
- 不复制任何现有商业游戏的剧情、旋律、台词或关卡；
- 不把 SQL 术语直接塞进怪物显示名；
- 不用尖锐高频、噪声墙和频繁静音制造“激烈”。

## 7. 核心循环

```text
观察地标与当前记录
→ 探索紧凑区域
→ 遭遇怪物或调查机关
→ 阅读任务、完整字段与渐进提示
→ 写出完整 SQL
→ SQLite 返回结果并触发攻击 / 反击
→ 获得 XP、确定奖励或低概率即时恢复
→ 打开回程捷径
→ 在篝火休息、换装和复盘
→ 击败区域首领与楼层 Boss
→ 通过实体交通上升
```

每次提交是一回合。空输入不耗回合；错误结果和语法错误才触发已预告反击。玩家思考时没有计时器。

## 9. 地图与 Seed

### 9.1 宏观规则

- 新 Run 地图目标尺寸为 `48×36`，较旧 `64×48` 减少约 44% 单元格；
- 每层 10–11 个课程 / 功能房，主路宽 2–4 格，房间边界不要求规则方形；
- 每层固定三个前 / 中 / 后区域、三个篝火、两个可回程结构；
- 主线相邻目标步行间隔目标为 6–14 步，任何必要目标不超过 18 步；
- 主路线包含至少一个“远路抵达后从背面开启”的永久捷径；
- 区域门以水闸、船、墓门、升炉、吊桥、矿车、晶门和长阶表现，不用同一图标换色；
- 出生点和篝火安全区不刷新怪物，普通巡逻怪不能进入。

### 9.2 固定与随机

固定：

- 区域顺序、课程锚点、Boss 区、篝火阶段、关键门、捷径功能；
- 必修课程、字段数据、关键武器、钥匙、证据和主线奖励。

Seed 控制：

- 宽路的局部转折、非关键连接、装饰密度；
- 怪物巡逻初始位置、合格步随机遭遇、低概率即时恢复；
- 不影响通关的死路补给和视觉小变化。

刷新、死亡、休息和旧存档加载都不能重抽已确定结果。旧 `generatorVersion: 4` 地图继续加载；
新 Run 使用新生成器，不删除永久 SQL 图鉴。

## 10. 角色与怪物视觉

制作参考见
[MVP 2.0 角色进化参考图](./assets/mvp2/character-progression-reference-v1.png) 与
[生成 / 转译记录](./assets/mvp2/README.md)。参考图不进入运行时 Bundle；正式模型仍由下述
程序化配方实时绘制。

### 10.1 玩家

玩家保持清楚的 1 格轮廓，随身份理解分四阶段显形：

| 阶段 | 楼层 | 外观 |
|---|---|---|
| 无键者 | 1–2 | 蓝灰短衣、纸白面部、黄铜查询杖 |
| 归档者 | 3–4 | 增加深色披肩和青色档案边 |
| 迁移者 | 5–6 | 黑铁护肩、夕阳红内衬、武器轮廓加强 |
| 历史集合 | 7–8 | 黑金长衣、青色索引光、保留最初蓝灰布料 |

装备改变武器、护甲和少量颜色叠层，不改变碰撞箱。世界与战斗使用同一份外观配方。

### 10.2 抄写员

- 位于每个篝火安全区边缘，不阻挡道路；
- 灰白短发 / 兜帽、深墨长衣、暖琥珀灯和纸页；
- 永远面向篝火或玩家，动画只保留呼吸、翻页和灯光；
- 不新增第三个篝火主操作：现有 `在此休息`、`答案复盘` 仍是核心，角色台词显示在菜单内；
- 她只总结本层已经发生的事实，不替玩家答 SQL。

### 10.3 怪物

- 显示名使用 2–4 个直白中文字符；
- 每个 `MonsterVisualArchetype` 只有一个模型真源，同时生成地图和战斗尺寸；
- 普通怪、精英、区域 Boss、楼层 Boss 通过轮廓、尺寸、冠饰和动作幅度区分；
- 每个模型至少有待机、受击、攻击三个低帧状态；
- 青蛙必须始终像青蛙，任何未映射模型显示明确调试占位并使自动化失败；
- 每层怪物强度上升，普通 / 精英 / Boss 经验仍为 `1 / 3 / 5`。

## 11. 战斗、成长、装备与掉落

以下 `CURRENT` 行为原样保留：

- 初始生命 2；
- 累计升级阈值为 `2、4、6、8`，之后每 4 XP 一级；
- 升级增加 1 点生命上限并恢复 1 点生命；
- 护甲先于基础生命承受伤害；
- 12 格装备背包、1 武器、1 防具、3 个恢复品堆栈；
- 撤退回到复活点但不回血，敌人当前 HP 保留；
- 死亡显示 `YOU DIED`，自动回最近休息篝火并满血，随后打开本场复盘；
- 普通 / 小精英 / 区域 Boss / 楼层 Boss 的随机即时恢复概率为
  `2% / 5% / 10% / 0%`；
- 随机掉落没有保底且不掉随机装备；课程装备、钥匙、宝箱和主线证据保持确定性。

MVP 2.0 只增加装备的可见外观层，不重开高频装备掉落或多掉落经济。

## 12. 叙事与失名录

主线叙事通过四个渠道表达：

1. 层首不超过三行的地区引导；
2. 必然经过的环境地标；
3. 篝火菜单中的抄写员短句；
4. 本地《失名录》中的已发现证据。

《失名录》只根据当前楼层和已完成课程解锁，不联网、不调用 Agent、不记录移动或按键。每层至少
解锁一条必然证据；关键真相不进入随机掉落。

层末演出由当前地图实体承接：

| 层 | 上升设施 |
|---:|---|
| 1 → 2 | 档案货梯抵达潮汐码头 |
| 2 → 3 | 北岸渡船靠向白霜墓原 |
| 3 → 4 | 墓城竖井进入山腹 |
| 4 → 5 | 元素升炉冲上外城 |
| 5 → 6 | 吊桥与矿车抵达龙脊 |
| 6 → 7 | 王室升降台进入云海王苑 |
| 7 → 8 | 晶体长阶展开至黑金高堂 |

## 13. 音乐与声音

音乐全部由项目内声明式音符和 Web Audio 合成，不使用外部录音、MIDI、采样或受版权保护旋律。

每层提供三套原创乐章与一个不重启乐句的篝火聚焦状态：

- `hearth`：沿用当前探索乐章并切入 `thinking` 聚焦，降低总增益与滤波上限，避免开关篝火时断句；
- `explore`：连续底床 + 分句主题；
- `combat`：同主题加快、加入低音切分，但不尖锐；
- `boss`：扩大低中频层和节奏密度，保留可辨识主题。

连续性规则：

- 底层持续音跨乐句延续，不在短句结束后归零；
- 同层区域切换优先交叉淡化参数，不销毁整个调度器；
- 打开 SQL 终端时降低节奏和高频密度，不停止音乐；
- 普通状态切换淡化 350–700 ms，层间转场淡化 900–1,500 ms；
- 主旋律峰值低于事件音效，战斗不使用噪声墙；
- 第 1 层以柔和三角 / 正弦和低音提琴式长音建立“家”，第 8 层用低中频圆号式长句和大提琴式
  持续声形成辉煌而凄凉的高堂。

## 14. UI、可访问性与性能

- 保留 Q+S、WASD / 方向键、E、B、触屏方向键与撤退按钮；
- SQL 输入、完整字段、表角色、渐进提示和真实结果保持最高视觉优先级；
- 新增《失名录》入口与层首 / 层末叙事，但不遮挡战斗输入；
- 管理员模式可切换八层、区域、课程节点和故事节点，仍不写正式存档；
- 目标 30 FPS；地图静态地形一次绘制，低帧动画用少量 Timer / Tween；

## 17. 风险与取舍

| 风险 | 处理 |
|---|---|
| 一次重做八层范围大 | 先建立共享模板和模型真源，再按层填内容；每阶段有本地 commit |
| 手工拓扑破坏课程可达性 | 地图生成后执行可达性、路径间距、篝火与捷径校验 |
| 旧 Run 与新地图不一致 | 结构不变时兼容旧 generator；必要时只迁移一次性 Run，永久 Profile 保留 |
| 程序化模型看起来像占位 | 使用统一轮廓、调色、动作状态和地图 / 战斗同源配方 |
| 音乐长期疲劳 | 控制高频、限制声部、终端降密度、连续底床与长淡化 |
| 用户不在无法主观试玩 | 自动化与浏览器证据必须完成；主观音乐、手感和逐字文案诚实列为后续人工复核 |
