# Game Documentation Boundary

The public download keeps the playable game, runtime assets, source code, and tests. Development-only design drafts, production notes, historical reports, and preview recordings are intentionally not shipped under `game/docs/`.

Current player-facing information lives in:

- [`../README.md`](../README.md): 默认中文的安装、操作、课程与隐私说明。
- [`../README.en.md`](../README.en.md): English setup, controls, curriculum, and privacy notes.
- [`../README.zh-CN.md`](../README.zh-CN.md): 中文兼容入口（可选）。
- [`../GUIDE.md`](../GUIDE.md): the extended in-game guide.

Stable implementation facts remain in [`../ARCHITECTURE.md`](../ARCHITECTURE.md) and its Chinese translation. Git history is the source for retired design and release records.
