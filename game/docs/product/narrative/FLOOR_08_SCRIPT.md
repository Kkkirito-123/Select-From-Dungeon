# 第八层逐事件叙事脚本：黑金迁移高堂

> 脚本版本：`v1.1` · 状态：`RUNTIME V1.1 VERIFIED`
>
> 目标时长：首次 `45–65` 分钟
>
> 课程：`MVCC 快照 / 锁与死锁 / 隔离级别 / 建模 / 复制 / 分片 / 安全与迁移`

## 0. 本层职责

第八层汇总前七层证据，但不假装 SQLite 浏览器游戏真实模拟分布式数据库。并发、复制和分片使用
确定的事故记录表与只读查询进行教学；最终 `MIGRATE` 是工程流程，不是一条万能 SQL。

本层问题：

> 应当提交旧命令、全部回滚，还是继续让王国停在未完成状态？

唯一结论：

> 都不是。建立只读快照，审计冲突，保留历史，在隔离环境构建并验证新版本，再切换且保留回滚。

## 3. 抄写员与档案官

抄写员入层：

> “七层证据都在这里。”
> “这一次我不替你总结；我只确认每一项从哪里来。”

零行礼拜堂：

> “第一层的空白页没有变成某一个名字。”
> “它现在能与所有历史共同解释你为什么仍站在这里。”

最后的档案官：

> “我保住了回滚，却让整个王国停在回滚之前。”
> “如果你要接管写权限，就证明你能让历史和明天同时存在。”

档案官不是“反对保存历史”的反派。她的战斗阶段分别质疑快照完整性、冲突审计、权限边界、验证
结果和回滚准备；玩家通过五阶段事故响应证明迁移可以开始。

## 4. SQL 密文：王令校验密文

题目从副本健康记录中为每个区域选择“健康且最新”的候选。它检验分区、排序、状态过滤和并列规则，
但不执行真实路由切换。

成功：

- 王座侧门永久开；
- 迁移台增加“预切换校验通过”状态；
- 不跳过最终安全题和 Boss；
- 不发放写权限或课程掌握。

现场证据：

- `f8-visible-snapshot`：按事务 12 的可见性条件返回三条当前版本。
- `f8-deadlock-cycle`：返回 T1、T2 两条反向等待边，证明闭合环存在。
- 两条证据均来自确定事故表；它们不宣称浏览器内真实运行了复制、分片或 MVCC 引擎。

## 5. 零行礼拜堂与王者甲

前置：MVCC、死锁、隔离三项。礼拜堂把第一层 `0 rows`、第二层七个来源、第三层关系网和后续层
证据并列展示，明确玩家是历史集合，而不是等待揭晓的唯一真名。

确定奖励 `royal-armor`：

- 视觉：黑金肩甲、白石内衬、保留一盏青色回滚灯。
- 功能：最终层护甲，不改变结局。
- 叙事：玩家可以携带王权，但不能获得免于审计的特权。

## 6. `MIGRATE` 七步

1. `snapshot`：保存只读快照。
2. `audit`：审计冲突、缺失和等待环。
3. `preserve-history`：保留历史版本与来源。
4. `build-isolated`：隔离构建新结构。
5. `validate`：验证数量、关系、约束和访问路径。
6. `switch`：切换到新版本。
7. `keep-rollback`：保持明确回滚路径。

完成画面不是爆炸或清空地图：残晖缓慢变成晨线，旧版本窗仍在，回滚灯未熄灭。

## 7. 验收

- 四个证据翼分别对应真实课程，不是四块换色房间。
- 未完成四翼时迁移台明确显示缺项。
- 最终剧情不提前泄露 `MIGRATE` 七步全文。
- 玩家完成后，《失名录》能回看八层因果链。
- 结局保留旧历史和回滚灯，不出现“全部删除成功”。
- Reduced Motion 和静音下仍能通过窗格、等待环、翼灯与晨线理解状态。
