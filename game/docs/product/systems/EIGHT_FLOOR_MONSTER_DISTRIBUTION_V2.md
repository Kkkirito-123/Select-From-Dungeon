# 《SELECT FROM 地牢》八层怪物分布设计 V2

> 文档版本：`0.1`
>
> 日期：`2026-07-30`
>
> 状态：`DESIGN LOCK / IMPLEMENTATION PENDING`
>
> 兼容目标：保留 ID #001–#089、课程顺序、两颗初始生命、经验阶级、低概率即时恢复品与胜利后姓名回收

## 1. 本次目标

把八层怪物从“课程对象清单”整理为可制作的生态与遭遇系统：每只怪物知道自己为什么出现在这个
区域、复习哪项已学知识、在剧情中证明什么、是否允许随机、何时揭示姓名，以及击败后产生什么
明确反馈。分布必须服务探索节奏，不能把地图重新变成连续战斗走廊。

## 2. 用户与干系人

| 对象 | 需要得到的结果 |
|---|---|
| 初学玩家 | 怪物难度可预期，精英不突然考未学语法，失败后知道错在哪里 |
| 探索玩家 | 不同生态有不同轮廓、行动与出现逻辑；安全区、隐藏房和 Boss 前有喘息 |
| 叙事玩家 | 击杀前只面对编号，胜利后姓名、生态和剧情职责一起进入图鉴 |
| 关卡 / 战斗 / 数值 | 固定 ID、区域槽位、Stage、XP、掉落和门控职责清楚 |
| 工程 / QA | 能验证 Seed 稳定性、区域归属、可达性、题阶、身份和掉落边界 |

## 3. MVP 范围

- 冻结五类遭遇职责、八层生态分布、主线硬门、重复命名修订和区域题阶；
- 保留全部现有怪物 ID，定义当前名与目标显示名的迁移；
- 给出前 / 中 / 后区节奏、安全排除、随机遭遇和图鉴交付规则；
- 登记 HP、伤害、Stage、SQLite 房间和物理区域的现有错位；
- 给出分批实施与验收标准。

## 4. 本轮不做

- 不在本 PR 修改怪物代码、HP、实际扣血、SQL 数据、地图位置或素材；
- 不改 ID、不重排 47 组课程、不新增随机装备；
- 不让高层怪用更高单次反击直接秒杀两颗初始生命；
- 不把历史设计中的 Boss 保底多掉落、F8 20% 精英或 `damage` 展示值当作当前事实。

## 5. 当前运行事实与目标值

### 5.1 遭遇阶级

| 类型 | 出现方式 | 正确回答目标 | XP | 随机恢复品 | 主线职责 |
|---|---|---:|---:|---:|---|
| 固定普通课程怪 | 稳定课程房，非随机 | 1–2 次 | 1 | 不用随机掉落保证进度 | 教一个新概念并改变世界 |
| 固定课程精英 | 稳定课程房，非随机 | 2 次 | 3 | 同上 | 组合本层已学概念 |
| 随机普通生态怪 | 当前生态、Seed 判定 | 1 次 | 1 | 2%，命中即使用 | 低压复习，不推进主线 |
| 随机小型精英 | 当前生态、Seed 权重 | 2 次 | 3 | 5%，命中即使用 | 两项本层基础知识复合复习 |
| 区域首领 | 地图可见固定 Actor | 2 次 | 3 | 10%，命中即使用 | 中区硬门或明确支线世界变化 |
| 楼层 Boss | 后区固定 Actor | F1–2：2；F3–4：3；F5–7：4；F8：5 | 5 | 0% | 反驳本层错误结论并结业 |

“正确回答目标”是下一版设计目标。当前运行时战斗轮数由 `stages.length` 决定，完成最后一 Stage 会
直接击杀；`hp` 主要用于回合表现，`damage` 也不是实际扣血真源。实施时必须先统一这三个概念，
不能只把 HP 数字调大后宣称需要更多次攻击。

### 5.2 当前随机遭遇

- 新 Run 初始 5 个符合条件的安全步，战斗后再保护 5 步；
- 安全区外每个符合条件的成功移动以 2% 判定，30 个安静步保底；
- 刷新不能重抽；候选只来自当前楼层、当前生态和已解锁题阶；
- 小型精英权重 F1–F8 依次为 `5 / 7 / 9 / 11 / 13 / 15 / 17 / 19%`；
- 出生安全房、两座篝火圈、主框演出、区域转场、隐藏房、Boss 门前缓冲都不产生随机遭遇；
- 随机胜利不授予课程掌握、钥匙、武器或防具。

### 5.3 目标抗疲劳规则

| 规则 | 目标 |
|---|---|
| 连续随机战 | 同一课程锚点之间最多 1 场；战后 5 步继续保持 |
| 同 ID 重复 | 最近 2 次随机遭遇不得再次抽到同 ID；候选不足时宁可不触发 |
| 同视觉家族 | 连续 3 场不得使用相同轮廓与相同题型组合 |
| Boss 前缓冲 | 区域首领与层主可见范围内不刷随机怪，不放一次性陷阱 |
| 隐藏房 | 不随机刷怪；只有明确标注的宝箱怪、证据或确定性换装 |
| 退路 | 区域首领可撤退到复活点；不因撤退重置其 HP 或换题 Seed |
| 题阶 | 普通只用当前已解锁的一阶题；小型精英组合两道已学基础题；不得预习后区语法 |

## 6. 身份、命名与图鉴协议

1. 地图、战斗首屏、任务、反击预告、字幕、ARIA 文本和 SQL 错误反馈只显示 `ID #NNN`；
2. 最后一击的查询可以返回姓名，但在判定胜利前不提交永久身份；
3. 胜利先播放击杀反馈，再显示 `NAME RECOVERED / 获得名字`，随后写入永久图鉴；
4. 图鉴包含真名、生态、遭遇角色、本次用于确认身份的证据和已掌握课程，不显示内部物种键；
5. 撤退、死亡、Escape、语法错误和空查询都不能提前回收姓名；
6. 名称使用 2–4 个直白汉字，不加间隔点、称号或 SQL 后缀；同层不重名；
7. ID #084 战斗中仍称 `ID #084`，胜利后图鉴将表面身份“魔王”统一揭示为“档案王”。

## 18. 反馈与表现验收

每场胜利依次交付：

1. 最后一击攻击动画与明显命中停顿；
2. 怪物退场，而非 UI 与 Actor 同时瞬间消失；
3. `NAME RECOVERED` 真名揭示；
4. `+1 / +3 / +5 XP`、当前等级进度和升级变化；
5. 随机恢复品若命中，明确显示“已直接使用”和恢复量；未掉落时不弹空奖励框；
6. 区域首领 / 层主触发专属世界变化、镜头和下一目标；
7. 图鉴新增状态可从 HUD 打开复查。

Reduced Motion 下取消屏幕震动和长位移，但保留颜色、轮廓、音量包络、文本和结算顺序。

## 19. 验收标准

### 19.1 自动化

- ID #001–#089 连续、唯一、跨存档稳定；
- 同层胜利后名称唯一，击杀前所有玩家可见字符串无姓名；
- 三区生态池非空；F6/F7 后区至少有一个普通候选；
- 每个随机精英恰有至少 2 个已解锁 Stage；
- 每个区域首领的 SQL `room_id/sector` 与物理区映射一致；
- F2 middle→rear 只由 #022 门控，#021 不阻塞；F3–F8 对应守卫不可由步行、捷径或传送绕过；
- 安全房、篝火圈、隐藏房、演出格和 Boss 缓冲无随机怪与巡逻进入；
- 2% 判定、30 步保底、5 步保护和 5–19% 精英权重在 Seed 下可复现；
- 普通/精英/区域/层主 XP 为 1/3/3/5；掉落为 2%/5%/10%/0%，且只有即时恢复品；
- 20 Seed/层验证主线与题阶，30 Seed/层验证生态、重抽稳定和重复抑制。

### 19.2 真人 QA

- 玩家能仅靠轮廓、行动和地形判断生态，而不是读取内部 Species；
- 15 分钟内不会出现三场视觉与题型都相同的随机战；
- 区域首领可发现、可撤退、战后门与环境变化明确；
- 高层难度来自组合、判断与阶段数，不来自无预告一击秒杀；
- 名字揭示、XP、升级、恢复品和世界变化均有可感知反馈；
- F8 最后揭示“档案王”时，玩家能理解他与此前“魔王”是同一身份。
