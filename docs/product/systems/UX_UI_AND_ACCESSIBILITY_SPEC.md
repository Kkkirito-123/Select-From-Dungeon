# UI、UX、反馈与可访问性规格

> 文档版本：`1.0`
>
> 状态：`F1_F2 IMPLEMENTED / UX CONTRACT`
>
> 目标设备：桌面博客页、iframe、触屏浏览器、最窄 320 CSS px

## 1. 体验目标

玩家应始终知道四件事：

1. 我现在在哪里；
2. 我能做什么；
3. 这道 SQL 到底要求哪个表的哪个字段；
4. 我的操作让怪物、地图、角色和学习进度发生了什么。

UI 服务游戏和学习，不模拟复杂商业 IDE。它必须专业、清楚、有像素世界气质，同时避免侧栏、
弹窗、状态卡和世界标签互相争夺注意力。

反目标：

- 不把所有系统永久铺在屏幕四周；
- 不用 10 px 小字塞完整 Schema；
- 不让补全列表遮住任务和输入光标；
- 不用颜色作为唯一状态；
- 不让短提示比最终答案更长；
- 不在怪物名字未发现时通过任务、补全、战斗标题提前泄露；
- 不用移动三步仍不消失的大型结算卡遮挡地图。

## 2. 信息架构

### 2.1 三层注意力

| 层级 | 内容 | 默认状态 |
|---|---|---|
| L1 世界 | 地图、角色、怪物、地标、环境状态 | 永久可见 |
| L2 行动 HUD | HP、等级、武器、防具、当前目标、交互提示 | 永久精简 |
| L3 专注面板 | SQL、背包、篝火、图鉴、剧情日志、管理员 | 一次只打开一个 |

L3 打开时，世界可以变暗但不得完全丢失战斗对象和生命状态。关闭后焦点返回触发该面板的世界
对象或玩家角色。

### 2.2 全局导航

| 功能 | 键盘 | 触屏 | 可用模式 |
|---|---|---|---|
| 移动 | WASD / 方向键 | 虚拟摇杆 / 四向按钮 | 探索 |
| 调查 / 拾取 / 休息 | E | 行动按钮 | 探索、邻近对象 |
| SQL 战斗 | Q+S 或行动按钮 | SQL 按钮 | 有当前遭遇 |
| 背包 | B | 背包按钮 | 探索、篝火、结算后 |
| 图鉴 / 失名录 | C | 图鉴按钮 | 非强制演出 |
| 下一提示 | H | 提示按钮 | SQL 面板 |
| 执行 | Ctrl/Cmd+Enter | 执行 SQL | SQL 面板 |
| 关闭 / 返回 | Esc | 关闭 | 可关闭面板 |
| 撤退 | 面板按钮 | 面板按钮 | 战斗 |

同时按 Q+S 只负责打开 SQL，不向输入框写入字符，也不触发移动。输入框聚焦时，WASD、Q、S、B、
C 不再驱动世界；Esc 先关闭补全，再关闭面板。

## 3. 探索 HUD

### 3.1 顶部状态栏

从左到右：

```text
生命 HP / MAX
等级 LV · 当前 XP / 下一阈值
当前武器
当前防具 / 护甲生命
关键物 / 当前层证据数
```

最窄屏改为两行，不横向滚动。只显示当前装备名称，不展示完整说明。

状态变化：

- 受伤：对应条瞬时闪白后减小；
- 护甲吸收：先闪护甲，不误闪基础 HP；
- XP：数字增加，升级时才扩大；
- 获得装备：名称短暂高亮并可按 B 查看；
- Reduced Motion：取消飞行动画，保留数字、边框和声音反馈。

### 3.2 当前目标

目标卡只显示一个主目标和一个可选目标：

```text
主线：启动档案水轮
方向：沿排水渠向东
可选：调查登记厅背后的封闭闸门
```

不显示答案，不使用“去地图右上角”之类脱离世界的描述。目标更新后，在 3 次成功移动内缩成一行；
玩家可随时展开任务日志。

### 3.3 世界标签

| 对象 | 常亮内容 | 近距离追加 |
|---|---|---|
| 未发现怪物 | `ID #001`、HP 条、意图图标 | `Q+S 调查` |
| 已发现怪物 | 真名、ID、HP 条 | SQL 弱点摘要 |
| 抄写员 | `抄写员` | `E 交谈` |
| 篝火 | 独特地名 + 篝火图标 | `E 休息 / 复盘` |
| 门 / 水闸 / 船闸 | 状态名 | `E 调查`、缺少条件 |
| 宝箱 | 图标，不提前列完整内容 | `E 打开` |
| 船 | 航线目的地 | `E 登船` |

NPC 名字常亮；怪物真名受身份状态控制。标签拥有避让和最大宽度，不能与玩家、怪物、篝火、
战斗 HUD 堆成一团。低缩放时只保留主对象标签，按检查键显示其余。

## 4. SQL 战斗面板

### 4.1 布局

桌面宽屏：

```text
┌ 回合、知识点、怪物意图、关闭 ┐
├────────────┬──────────────────┤
│ 任务合同    │ SQL 编辑器        │
│ 表与字段    │ 补全 / 结果 / 提示 │
├────────────┴──────────────────┤
│ 执行 SQL │ 下一提示 │ 撤退       │
└───────────────────────────────┘
```

窄屏：任务合同 → 表与字段折叠 → 编辑器 → 结果 / 提示 → 固定底部操作；面板可纵向滚动，但执行、
提示和撤退始终可达。不得将编辑器压缩到不足 160 px 高。

### 4.2 任务合同

任务不是自然语言谜语，必须结构化展示：

| 字段 | 示例 |
|---|---|
| 本回合目标 | 连接怪物主表与房间主表，确认 ID #012 所在区域 |
| 主表 | `monsters AS m`（怪物主表） |
| 关联表 | `rooms AS r`（房间主表） |
| 返回字段 | `m.id`、`r.sector` |
| 连接条件 | 由玩家写出；字段速查显示关系 |
| 过滤条件 | `m.id = 12` |
| 需要别名 | `m`、`r` |
| 允许结构 | `SELECT / FROM / INNER JOIN / ON / WHERE` |
| 敌方意图 | 错误后造成 1 点伤害 |

任务正文必须复述字段归属：

> 将怪物主表写为 `monsters AS m`，房间主表写为 `rooms AS r`。返回怪物主表字段
> `m.id` 与房间主表字段 `r.sector`；通过 `m.room_id = r.id` 连接，只保留 `m.id = 12`。

不允许：

> 查询 id = 12 的 name 与 sector。

### 4.3 Schema 速查

每张参与表独立卡片，显示：

```text
monsters AS m                 怪物主表 / 本题主表
PK id          INTEGER        怪物唯一 ID
FK room_id     INTEGER        → rooms.id
   name        TEXT           怪物名字（最后一击才永久揭示）
   weakness    TEXT           弱点
```

字段必须完整，不以省略号截断关键字段。空间不足时卡片内部滚动。主表、关联表、参考表用文字与边框
共同区分。关系线只在两表任务中显示，避免四表全铺造成噪声。

`monster_id` 只出现在 `monster_signals` 和 `monster_gear` 明细表；任务若在 `monsters` 上使用
`monster_id`，错误解释必须指出主表主键是 `monsters.id`。

### 4.4 编辑器与补全

最低字号：桌面 22 px，窄屏 18 px；行高 1.5。使用等宽字体，光标、选区、错误下划线具有足够
对比度。

补全排序：

1. 当前光标语境的表别名字段；
2. 本题要求字段；
3. 当前参与表；
4. 合法 SQL 关键词；
5. 其他 Schema 字段。

输入 `r.` 只建议 `rooms` 字段；输入 `m.na` 优先建议 `m.name`。候选展示完整归属和说明：

```text
FIELD  r.sector   rooms.sector · 房间区域
FIELD  r.name     rooms.name · 房间名称
KWD    INNER JOIN 连接同时存在的记录
```

键盘：上下选择、Enter / Tab 接受、Esc 关闭、Ctrl+Space 手动打开。触屏点击接受。补全不得自动
写入玩家未确认的完整答案；最终提示可以一键填充，但必须标记“使用完整答案”。

### 4.5 四级提示

提示长度与信息量严格递增：

1. **概念**：只提醒 SQL 思路，不给字段或值；
2. **骨架**：给关键词结构和表的角色；
3. **精确**：给完整表名、字段、别名、连接 / 过滤值，不给完整拼接答案；
4. **答案**：给可执行完整 SQL，并解释每一段。

示例：INNER JOIN 第一阶段：

```text
提示 1：需要把“怪物所在房间”与“房间区域”连接起来。
提示 2：使用 SELECT … FROM … INNER JOIN … ON … WHERE …。
提示 3：monsters AS m；rooms AS r；ON m.room_id = r.id；返回 m.id、r.sector；m.id = 12。
提示 4：SELECT m.id, r.sector FROM monsters AS m INNER JOIN rooms AS r
        ON m.room_id = r.id WHERE m.id = 12;
```

提示使用记录进入复盘，但不扣 XP、不改变掉落概率。可选的“无提示通关”仅作为成就，不能影响
核心成长。

### 4.6 执行与结果

执行后按顺序展示：

1. SQLite 原始状态：成功 / 语法错误 / 运行错误；
2. 真实结果表，列名和行值可横向滚动；
3. 任务判定：结构、结果、过滤、别名是否符合；
4. 世界 / 战斗结果：命中、反击、环境变化；
5. 下一阶段目标。

正确 SQL 但任务不匹配时，不把数据库结果说成“语法错误”。示例：

```text
SQLite：执行成功，返回 3 行。
任务判定：尚未命中。本回合只需要 ID #012，请补充 WHERE m.id = 12。
敌方反击：1 点伤害。
```

错误必须直白：

```text
no such column: r.room_name
rooms 表没有 room_name 字段；房间名称字段是 r.name。
若结果列需要叫 room_name，请写 r.name AS room_name。
```

## 5. 战斗反馈

### 5.1 正确命中

最低反馈链：

1. 对应 SQL 关键词 / 字段在编辑器中高亮；
2. 结果行转化为世界粒子或连线；
3. 玩家攻击动作；
4. 怪物受击、HP 减少；
5. 环境对象同步变化；
6. 文字说明“为什么命中”。

不能只让双方同时消失。

### 5.2 错误反击

- 提交前显示敌方意图；
- 错误后先展示原因，再播放反击；
- HP 与护甲变化同步；
- 反击动画 250–450 ms，可快速跳过；
- 连续错误不叠加多层弹窗；
- 死亡时完成当前错误记录后进入死亡流程。

### 5.3 击杀强反馈

普通怪总时长 1.2–1.8 秒，Boss 2.5–4.0 秒：

```text
最终结果锁定
→ 伤害停顿 80–120 ms
→ 怪物轮廓碎裂 / 溶解 / 坍塌（按物种）
→ 低频冲击与屏幕轻震
→ ID 行翻转为真名
→ 图鉴页印章
→ XP 飞向状态栏
→ 奖励 / 世界状态
```

名字大字不得被战利品或升级卡覆盖。Reduced Motion 下去掉震动和大位移，保留轮廓闪白、文字、
声音和状态变化。

### 5.4 短卡生命周期

以下卡片在之后 3 次**成功移动**后自动折叠：

- XP 结算；
- 升级摘要；
- 装备说明摘要；
- 无随机掉落说明。

撞墙、转向、打开菜单、航行动画、剧情自动移动不计数。名字恢复、关键证据和楼层通关必须由玩家
确认，且永久可从图鉴 / 日志回看。

## 6. 篝火与复盘 UX

### 6.1 篝火菜单

面板标题使用该篝火地名和当前复活状态：

```text
水轮余烬
当前复活点：登记厅余烬锚点（尚未在篝火休息）

[在此休息]
恢复 1 / 3 HP 与 1 / 1 护甲，并将复活点改为这里。

[答案复盘]
查看本层 8 次提交、2 个错误和已掌握知识。
```

选择休息后显示实际恢复数和新复活点。已满血仍允许休息和设点，但必须说“生命已满；复活点已
更新”，不能看起来无响应。

### 6.2 复盘层次

1. 本层摘要：知识点、正确率、提示使用、死亡次数；
2. 按遭遇分组；
3. 每次提交：玩家 SQL、结果 / 错误、任务差异、正确答案；
4. 一道变式迁移题，可选择稍后做；
5. 抄写员只总结已发生事实，不生成 AI 内容。

死亡自动复盘只显示导致死亡的本场，避免信息过载。

## 7. 图鉴与失名录

### 7.1 入口与结构

`C` 打开，分为：

- 怪物图鉴；
- 失名录 / 剧情证据；
- SQL 图鉴；
- 地区档案。

### 7.2 未发现 / 已发现

未发现条目：

```text
ID #012
轮廓：已观察 / 未观察
所在层：潮汐群岛
真名：未恢复
```

已发现条目：

```text
树妖 · ID #012
栖息地：根桥岛
已见字段：id, room_id, name, weakness
恢复方式：INNER JOIN 最终阶段
生态说明 / 弱点 / 已见掉落
```

图鉴只展示玩家实际见过的字段和答案摘要，不把未来变式答案提前写出。Boss 条目额外记录它改变的
世界规则。

### 7.3 新条目反馈

首次恢复：右上角显示 `图鉴 +1`，不立即强制打开。击杀结算结束后可按 C 查看。楼层结束显示新增
条目清单。

## 8. 剧情与对话 UI

### 8.1 呈现方式

- 世界气泡：1–2 句即时反应；
- 对话面板：角色正面交流；
- 环境记录：短 SQL 结果或纸页；
- 失名录：可追溯长文本；
- 关键演出字幕：开场、Boss 和层间。

不使用长期占据侧栏的自动剧情卡替代世界表现。

### 8.2 文本预算

| 场景 | 单次预算 | 操作 |
|---|---:|---|
| 世界气泡 | 24 中文字左右 | 自动 / 可跳过 |
| 普通对话页 | 45 中文字左右 | 点击继续 |
| 环境记录 | 80 中文字左右 | 展开查看 |
| Boss 前后 | 每页 60 中文字左右，最多 4 页 | 可快进，日志可回看 |
| 层间演出 | 90–160 中文字总量 | 可跳过，不错过奖励 |

## 9. 地图、小地图与导航

- 小地图只显示已探索区域；管理员模式例外；
- 地标使用独特图标：水轮、宿舍、登记厅、码头、村落、灯塔；
- 当前位置、当前主目标、已开启捷径、篝火、Boss 门明确区分；
- 不显示所有怪物实时位置，除非已观察或管理员预览；
- F2 航线以实际水道连线，不使用通用传送门符号；
- 捷径开启时世界、碰撞、小地图和日志同一帧更新；
- 色盲模式为水位 / 门 /危险状态增加纹理或图形符号。

## 10. 管理员模式 UX

管理员入口与正式存档隔离。面板按层提供：

| 预设 | F1 | F2 |
|---|---|---|
| 初始 | 水位高、仅出生余烬锚点 | 潮位高、仅港口航灯与初始航线 |
| 教学后 | 水轮启动 | ORDER / DISTINCT 完成 |
| 中段 | 水位下降、宿舍显形 | 根桥接通、村落可见 |
| 捷径前 / 后 | 闸门关闭 / 开启 | 船闸关闭 / 开启 |
| 区域 Boss | — | 湖兽存活 / 击败、潮位对照 |
| Boss 前 | 必修完成、登记官存活 | 必修完成、灯塔守卫存活 |
| 通关 | 证据、钥匙、升降机 | 七页、灯塔停止覆盖、层门 |
| 身份 | 全部 ID / 全部已发现 | 全部 ID / 全部已发现 |
| 掉落 | 强制未命中 / 恢复命中 | 强制未命中 / 恢复命中 |

当前模式、Seed、世界状态和是否写存档必须常亮。退出管理员后恢复最后正式存档，不把预览状态写入。

## 11. 响应式与触屏

### 11.1 断点行为

| 宽度 | 行为 |
|---:|---|
| ≥1280 | 地图 + 右侧简化信息；L3 居中宽面板 |
| 768–1279 | 地图全宽；信息折叠；L3 覆盖 92% |
| 480–767 | 单列；顶部两行状态；底部操作栏 |
| 320–479 | 最低 18 px 编辑器；所有面板纵向滚动；无横向页面滚动 |

游戏画面保持可理解的像素缩放；不得仅通过整体缩小把文字压到不可读。

### 11.2 触屏

- 虚拟移动区和行动按钮互不重叠；
- 所有主要目标至少 44×44 CSS px；
- SQL 编辑器调用系统键盘后，执行 / 提示仍可见；
- 双指缩放浏览器不应触发角色移动；
- 不依赖 hover；
- 航行和演出可点按跳过。

## 12. 可访问性

### 12.1 视觉

- 正文对比度 ≥ 4.5:1；大字 ≥ 3:1；
- 颜色状态同时有图标、文字或纹理；
- 支持 100%–200% 浏览器缩放；
- 焦点环清楚；
- 可关闭闪烁、屏幕震动、背景网格和粒子；
- 不使用每秒超过 3 次的大面积闪光。

### 12.2 动效

`prefers-reduced-motion` 或游戏设置开启时：

- 移除屏幕震动、镜头冲刺、XP 长距离飞行；
- 航行动画缩短为淡出 / 淡入；
- 保留状态文字、轮廓变化和环境前后对照；
- 不影响输入窗口和剧情时序。

### 12.3 音频

- 独立音乐、音效、UI、环境音音量；
- 一键静音；
- 所有关键信息都有视觉等价反馈；
- 首次交互前音频未解锁不阻塞流程；
- 页面隐藏时暂停或平滑静音，恢复时不叠播。

### 12.4 输入与认知

- 支持纯键盘完成；
- 支持按键说明和可重绑定（两层先提供预设切换）；
- SQL 关键词不要求固定大小写；
- 中文任务与英文 Schema 并列解释；
- 不使用倒计时；
- 错误解释一次只指出最关键差异。

## 13. 状态与边界用例

| 场景 | 预期行为 |
|---|---|
| SQL 面板打开时按 W | 输入字符或无效，不移动世界 |
| 补全打开时按 Esc | 先关补全，第二次关面板 |
| 结果表宽于屏幕 | 表内横滚，页面不横滚 |
| 名字最终查询成功但演出被刷新 | 读档后恢复为完整已结算状态，不出现半揭示 |
| 休息时满血 | 明示满血，仍更新复活点 |
| 战斗中打开背包 | 只读，换装按钮禁用并说明原因 |
| 满包打开确定装备 | 进入待领取比较，不丢奖励 |
| 音频加载失败 | 显示非阻塞提示，游戏继续 |
| 320 px + 系统键盘 | 编辑器和执行按钮仍可达 |
| iframe 失去焦点 | 清除移动按键状态，恢复后不持续走路 |

## 14. 验收标准

## 15. 风险与取舍

| 风险 | 缓解 |
|---|---|
| 任务信息过多 | 默认突出“本回合目标”，Schema 按参与表折叠，提示渐进 |
| 大字号压缩编辑区 | 窄屏单列和内部滚动，不整体缩小 |
| 强击杀演出打断学习节奏 | 普通怪 ≤1.8 秒，可跳过；首次姓名恢复保留完整 |
| 补全变成自动答题 | 只补当前 token，完整答案只由第 4 提示提供并记录 |
| 过多状态卡遮挡地图 | 三层注意力、一次一个专注面板、3 步折叠 |
| 管理员功能太强导致误写存档 | 隔离会话、常亮预览状态、退出恢复正式快照 |
