# 第二层关卡圣经：潮汐群岛

> 关卡版本：`v0.1`
>
> 状态：`IMPLEMENTED VERTICAL SLICE / CONTENT LOCKED`
>
> 楼层知识：`ORDER BY / LIMIT / DISTINCT / INNER JOIN / ON / LEFT JOIN / IS NULL / 综合 JOIN`
>
> 目标时长：首次 30–45 分钟

## 1. 本层承诺

第二层必须在进入后的第一分钟就否定“又是一张换色迷宫”：

- 玩家从封闭地牢进入有远景、有岸线、有水面和天空反光的码头；
- 路线不再是连续走廊，而是岛屿、浅滩、沼泽、桥和短船程；
- SQL 用来排序信号、选择航线、点亮浮标、连接岛屿记录和改变潮位；
- 湖兽是区域状态 Boss，灯塔守卫是本层知识与剧情 Boss。

本层问题：

> 多个旧名字共享同一条恢复轨迹，它们是重复记录，还是不同的人？

本层结论：

> 它们来自不同地点和不同记录，不能因为恢复轨迹相同就覆盖成一个名字。

离开时提出：

> 这些不同名字之间是什么关系，又曾经属于谁？

## 2. 情绪曲线

```text
码头：第一次开阔与轻快
→ 浅滩：可选择、可探索
→ 月影湖：水下巨大影子带来不安
→ 芦苇沼泽：视野收窄、关系断裂
→ 沉水村落：七个旧生活痕迹
→ 船闸回航：冒险获得空间掌握
→ 灯塔：光明被用来抹平差异
→ 北岸：海面逐渐结冰
```

第二层不是纯蓝色地图。沙、木、芦苇、石、浅水、深水和灯塔必须具有不同纹理和轮廓。

### 3.3 移动方式

玩家仍只使用方向键和 `E`：

- 陆地和浅滩：正常移动；
- 短船程：靠近渡点按 `E`；
- 播放 0.8–1.3 秒小船转场；
- 转场中禁用随机遭遇；
- Reduced Motion 下使用淡入淡出和航向文字；
- 船不实现自由物理和任意驾驶；
- 船程必须连接明确地点，不能只用作装饰传送门。

## 5. 角色

### 5.1 玩家

进入第二层时：

- 保留第一层获得的纸页与装备；
- 第一次看见自己在水面有不止一个倒影；
- 倒影不会直接说明答案，只作为持续视觉悬念。

完成第二层后：

- 衣领或披风出现潮色边缘；
- 七名记录页进入剧情档案；
- 人物轮廓更加完整，但面部仍不是唯一确定形态。

### 5.2 抄写员

初始演出：

- 第一层升降机门打开；
- 她先于玩家把记录箱推到码头固定记录台；
- 她并非从篝火旁瞬移出现。

行动节拍：

- 排序后在记录台挂出浮标顺序；
- 去重后拒绝把相同轨迹合并成一张纸；
- 船闸开启时到码头边亲眼看七个倒影；
- Boss 前承认她过去也会把相似记录装订在一起；
- 结尾将七页分别编号，而不是替玩家选一个真名。

关键台词：

**抵达**

> “海面把同一段恢复轨迹送来了七次。”
> “先别叫它重复。我们还不知道它们从哪里来。”

**DISTINCT 后**

> “去重只能告诉我们有多少种值。”
> “它不能替我们判断，哪一种生命可以被删掉。”

**七个倒影**

> “它们站在不同的水里。”
> “如果只是重复，为什么每一个都在看不同的方向？”

**结尾**

> “我给它们编了七个页码。”
> “没有一个被写成你的真名——至少现在没有。”

### 5.3 灯塔守卫

世界标签：击败前 `ID #014`。

真名：`灯塔守卫`。

ID #014 的课程槽位统一重构为灯塔守卫，不再保留互相冲突的双重身份。

外观：

- 石质塔身和旧航标组成的高大守卫；
- 胸口有旋转灯室；
- 两臂是断桥和根须；
- 第一阶段照亮“多数记录”，第二阶段暴露被遮蔽的小岛记录；
- 不再使用仅换色的丛林巨人模型。

动机：

- 为避免海难，只保留出现次数最多、信号最强的航标；
- 同样规则被用于身份记录，导致少数名字被覆盖；
- 它认为“一个稳定名字”比“七个冲突记录”更安全。

### 5.4 湖兽

世界标签：击败前 `ID #021`。

真名：`湖兽`。

作用：

- 区域 Boss，不是楼层 Boss；
- 它盘踞在控制船闸的深潭；
- 正确排序和去重查询让玩家判断它何时浮出；
- 击败后潮位下降并开放回访内容；
- 不承担最终身份结论。

### 5.5 蛙王

世界标签：击败前 `ID #022`。

真名：`蛙王`。

作用：

- 可选区域 Boss；
- 使用本层基础 JOIN 的二阶组合题；
- 守护藤甲和一份被泥水泡坏的房间记录；
- 不阻塞主线；
- 不在每个 Run 必须击败。

## 6. 剧情节拍

### Beat 1：潮声有顺序

**触发**：从升降机进入码头。

**演出**：

- 先出现海面和远处灯塔，再显示 HUD；
- 七个浮标随机明灭，无法形成航线；
- 抄写员把七张湿纸分别摊开；
- 当前目标：“找到最强信号，而不是猜一条路。”

### Beat 2：第一条航线

**触发**：完成 `ORDER BY / LIMIT`。

**演出**：

- 浮标按 `charge DESC` 依次亮起；
- 小船从码头漂到可交互位置；
- 玩家第一次通过短船程到达浅滩；
- 正确 SQL 改变路线，而不仅是击败猎犬。

### Beat 3：重复水纹

**触发**：进入月影湖并面对 `ID #011`。

**演出**：

- 水蛇移动产生四道水纹；
- 两对纹路相同；
- `DISTINCT` 后只保留不同频道；
- 水纹各自指向不同岛屿，不被当成“删掉重复动画”。

**永久证据**：旧标识数量 `7`。

### Beat 4：水下村庄

**触发**：从浅滩第一次看见沉水村落。

**演出**：

- 只能看见屋顶、钟架和门牌；
- 湖底有巨大影子经过；
- 玩家可以调查日志选择绕开湖兽，或提前挑战；
- 主线不会强迫此时战斗。

### Beat 5：树根知道两端

**触发**：完成 `INNER JOIN`。

**演出**：

- 古树根分别连接怪物所在房间；
- 错误 JOIN 时根系产生明显笛卡尔错连，但不永久改变地图；
- 正确连接后形成桥；
- 房间 `rooms.name` 和怪物 `monsters.name` 的来源在 UI 中同时高亮。

### Beat 6：没有右侧记录

**触发**：完成 `LEFT JOIN / IS NULL`。

**演出**：

- 沉水门卫存在于怪物表，却没有装备记录；
- 毒蛙借助缺失记录躲在沼泽中；
- 玩家理解“保留左表，再检查右表空值”；
- 村落一扇此前无守卫标记的门打开。

### Beat 7：湖兽与退潮

**触发**：挑战 ID #021。

**演出**：

- 湖兽每回合在不同信号强度后浮出；
- 正确排序找出最高信号；
- 正确去重识别真实波纹；
- 击败后潮位下降；
- 村落、浅滩和中央船闸产生整体变化。

### Beat 8：船闸捷径

**触发**：从深潭一侧启动中央船闸。

**演出**：

- 水闸打开；
- 玩家乘短航线回到进入本层的码头；
- 七盏浮标依次亮起；
- 水面出现七道人形倒影；
- 抄写员从记录台走到岸边；
- 新目标自然指向“带着七份来源去灯塔”。

### Beat 9：灯塔的多数规则

**触发**：进入灯塔岛 Boss 区。

**演出**：

- 灯塔守卫将七条记录按数量和强度排序；
- 它只照亮第一名，其他记录从墙面消失；
- 玩家通过综合 JOIN 证明它们属于不同地区和实体链路；
- 它的“保留最多者”规则失效。

### Beat 10：七页，不是一个答案

**触发**：Boss 完成。

**演出**：

- 灯塔同时照亮七个方向；
- 玩家获得 5 XP、第二层钥匙和七名记录页；
- 抄写员分别装订七页；
- 北岸渡船自动靠岸；
- 离港时水面开始结霜，进入第三层现有流程。

## 7. SQL 课程与世界反馈

### 7.1 ORDER BY / LIMIT：ID #010

**阶段 1**

任务：

> 从信号明细表 `monster_signals` 返回属于 `monster_id = 10` 的 `channel`；
> 按 `charge` 从高到低排序，只保留最高一行。

```sql
SELECT channel
FROM monster_signals
WHERE monster_id = 10
ORDER BY charge DESC
LIMIT 1;
```

反馈：最强浮标亮起。

**阶段 2**

任务：

> 返回同一怪物信号的 `channel` 与 `charge`，按 `charge` 从高到低排序，只保留前两行。

```sql
SELECT channel, charge
FROM monster_signals
WHERE monster_id = 10
ORDER BY charge DESC
LIMIT 2;
```

反馈：两段航线按优先级出现，小船靠岸。

### 7.2 DISTINCT：ID #011

任务：

> 从 `monster_signals` 返回属于 `monster_id = 11` 的不同 `channel`；
> 使用 `DISTINCT` 去除相同值，并按 `channel` 升序排列。

```sql
SELECT DISTINCT channel
FROM monster_signals
WHERE monster_id = 11
ORDER BY channel;
```

反馈：

- 水面重复波纹合并；
- 不同频道仍各自保留；
- 三个岛屿方向显形；
- 强调 `DISTINCT` 处理结果值，不代表不同来源的人可以被覆盖。

### 7.3 INNER JOIN：ID #012

**阶段 1**

任务：

> 将怪物主表写为 `monsters AS m`，房间主表写为 `rooms AS r`；使用
> `m.room_id = r.id` 连接。返回怪物主表字段 `m.id` 与房间主表字段
> `r.sector`；只保留 `m.id = 12`。

```sql
SELECT m.id, r.sector
FROM monsters AS m
INNER JOIN rooms AS r ON m.room_id = r.id
WHERE m.id = 12;
```

反馈：未知 ID 与所在区域之间出现唯一正确根系，真名仍不显示。

**阶段 2**

任务：

> 保持同一连接，返回怪物主表字段 `m.name`，并把房间主表字段
> `r.name` 命名为 `room_name`；只保留 `m.id = 12`。

```sql
SELECT m.name, r.name AS room_name
FROM monsters AS m
INNER JOIN rooms AS r ON m.room_id = r.id
WHERE m.id = 12;
```

反馈：古树桥连接到正确岛屿；最后一击、姓名恢复与图鉴写入原子结算。

### 7.4 LEFT JOIN / IS NULL：ID #013

任务：

> 将怪物主表写为 `monsters AS m`，装备明细表写为 `monster_gear AS g`；
> 使用 `m.id = g.monster_id` 左连接。返回怪物字段 `m.id`，只保留
> `m.room_id = 24` 且右表 `g.monster_id IS NULL` 的记录。

```sql
SELECT m.id
FROM monsters AS m
LEFT JOIN monster_gear AS g ON m.id = g.monster_id
WHERE m.room_id = 24
  AND g.monster_id IS NULL;
```

反馈：

- 没有装备记录的毒蛙被定位；
- 村落无守卫门打开；
- UI 明确说明 `monster_gear.monster_id` 只属于装备明细表。

### 7.5 综合 JOIN：ID #014 灯塔守卫

**阶段 1：检查各区域实体数**

任务：

> 将 `monsters AS m` 与 `rooms AS r` 按 `m.room_id = r.id` 连接；
> 只统计第二层 `r.floor = 2`。按 `r.sector` 分组，返回 `r.sector` 与
> `COUNT(*) AS total`；只保留至少 3 条记录，并按 `total` 降序、
> `r.sector` 升序，使并列结果稳定。

```sql
SELECT r.sector, COUNT(*) AS total
FROM monsters AS m
INNER JOIN rooms AS r ON m.room_id = r.id
WHERE r.floor = 2
GROUP BY r.sector
HAVING COUNT(*) >= 3
ORDER BY total DESC, r.sector ASC;
```

反馈：灯塔承认多个区域都有可靠记录，第一层“只留多数”护盾消失。

**阶段 2：定位核心**

任务：

> 将 `monsters AS m` 与 `monster_gear AS g` 按 `m.id = g.monster_id` 连接；
> 只保留 `ID #014`（`m.id = 14`）。返回怪物字段 `m.name` 和装备字段
> `g.power`，按 `g.power` 降序，只保留最强一行。

```sql
SELECT m.name, g.power
FROM monsters AS m
INNER JOIN monster_gear AS g ON m.id = g.monster_id
WHERE m.id = 14
ORDER BY g.power DESC
LIMIT 1;
```

反馈：定位灯塔的主透镜，关闭覆盖其他记录的强光。

### 8.3 模型要求

- 猎犬：四足轮廓，不能显示成墙或方块；
- 水蛇：长形游动，水中与岸上阴影不同；
- 青蛙 / 毒蛙：明显腿部和跳跃姿态；
- 树妖：树干、冠层和根部三层；
- 湖兽：只在深水露出局部，战斗中显示完整轮廓；
- 灯塔守卫：塔灯、石体、断桥手臂，不复用旧森林巨人文字或模型。

怪物名字在发现前不常亮，ID 常亮；发现后真名与 ID 都常亮。

## 9. Boss

### 9.1 湖兽

定位：区域状态 Boss。

阶段：

1. 根据 `charge DESC` 判断浮出位置；
2. 使用 `DISTINCT` 区分真实波纹和重复水纹；
3. 最后一击触发潮位下降。

失败：

- 返回最近篝火；
- 潮位保持战斗前状态；
- 本场复盘显示排序和去重。

胜利：

- 3 或 5 XP 由数值契约最终统一；产品目标采用区域首领 5 XP；
- 水位下降；
- 沉水村落露出；
- 中央船闸可操作；
- 图鉴恢复“湖兽”。

### 9.2 灯塔守卫

定位：楼层 Boss。

阶段：

1. 连接区域并聚合可靠记录；
2. 使用 HAVING 保留多个有效区域；
3. 连接装备定位主透镜；
4. 关闭覆盖规则，而不是摧毁灯塔。

胜利反馈：

- 灯光从单束变为七束；
- 石体裂纹中飞出七张记录页；
- `ID #014 → 灯塔守卫`；
- 5 XP；
- 第二层钥匙；
- 七名记录页；
- 北岸渡船靠岸。

## 10. 回访与支线

### 10.1 船闸捷径

- 早期从码头看见封闭闸门；
- 击败湖兽后从深潭侧打开；
- 形成码头与后段的短航线；
- 回访触发七浮标、七倒影和抄写员行动；
- 后续挑战灯塔时真正节省路程。

### 10.2 沉水村落

退潮后新增：

- 七块不同门牌；
- 一份房间—怪物关联日志；
- 一个确定恢复品；
- 可选蛙王线索；
- 图鉴故事条目。

### 10.3 蛙王

- 可选；
- 不阻塞主线；
- 使用本层已学 JOIN；
- 确定奖励为藤甲；
- 不额外随机掉装备；
- 击败后沼泽出现安全踏石，减少回程疲劳。

## 11. 奖励与掉落

### 11.1 随机

- 普通怪：2% 水珠、蛙药或树果；
- 小型精英：5%；
- 区域 Boss：10%；
- 灯塔守卫：0%；
- 随机池没有武器和防具；
- 无掉落时使用小型结算文字，不展示空白大面板。

### 11.2 确定

| 来源 | 奖励 |

| ORDER BY 完成 | 雷序军刀 |
