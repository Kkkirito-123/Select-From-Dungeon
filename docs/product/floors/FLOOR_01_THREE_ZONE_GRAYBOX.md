# 第一层三区灰盒规格：双岸与失名迷宫

> 状态：`CURRENT_F1 / NEXT_V1_1_DESIGN_LOCKED`
>
> 版本：`1.1`
>
> 阅读规则：正文先记录已经进入运行时的三区灰盒，再单列已确认但尚未实现的 V1.1 宝箱、视野和
> 陷阱信息方案；不得把 `NEXT_V1_1` 条目作为完成事实。

## 1. 本次目标

把第一层从“许多色块房间散落在大地图上”改造成一眼能读懂、可以回忆路线、具有进退节奏的三段空间：

1. 左侧“余烬书房”是永久家园，承担出生、引导、换装、图鉴和第一次休息；
2. 中央“失名迷宫”承担全部敌对遭遇、SQL 课程、陷阱、隐藏库与随机探索；
3. 右侧“登记前哨”是从迷宫深处抵达的安全区，承担后段休整和 Boss 前准备。

目标用户是第一次接触 SQL 的玩家。空间必须帮助学习，而不是让寻路本身抢走注意力。

## 3. MVP 范围

### 3.1 当前运行时基线

- 第一层宏观结构固定为左安全区、中央迷宫、右安全区；
- 左右安全区完全可见，不生成怪物、伏击和伤害陷阱；
- 玩家首次从任一安全区踏入迷宫前，出现“是否进入迷宫”主框；
- 选择进入后完成原移动；选择暂不进入则留在安全区；
- 中央迷宫保留 Seed，可变化支路、死路补给和路线；
- 迷宫内视野缩小；已经走过但离开视野的区域保留暗色记忆；
- 第一层生成少量直接伤害陷阱，不进入 SQL 战斗；
- 右侧安全区的门在完成中段课程前锁住，完成后可从迷宫深处抵达；
- 第一层两个实体篝火分别落在左右安全区；
- 地图继续维持 48×36、30 FPS 目标和当前 Phaser + SQLite WASM 架构。

### 3.2 下一迭代必须完成（`NEXT_V1_1`）

- 中央迷宫明亮视野从曼哈顿半径 4 缩小为半径 3；安全区仍然完整可见；
- 每个 Seed 放置 4 个不重复宝箱：2 个普通奖励箱、1 个宝箱怪、1 个传送宝箱；
- 宝箱怪靠近后按 `E` 直接进入战斗，强度按第一层小 Boss 设计，课程只复用第一层已学知识；
- 传送宝箱先结算奖励，再把玩家送到迷宫内一个可回返、非 Boss 房、非死路的合格格；
- 陷阱入口说明不再直接写“会扣血”，只通过机关动画和环境文字提示风险；

## 4. 宏观布局

```text
┌──────────┐   首次进入确认   ┌────────────────────────┐   深处解锁   ┌──────────┐
│ 余烬书房 │ ───────────────▶ │       失名迷宫         │ ──────────▶ │ 登记前哨 │
│ 永久安全 │                  │ SQL / 怪物 / 陷阱 / 库 │              │ 永久安全 │
│ 抄写员   │ ◀── 后段捷径 ─── │ Seed 只影响这里        │              │ 篝火整备 │
└──────────┘                  └────────────────────────┘              └──────────┘
```

### 4.1 左侧：余烬书房

- 固定房间：`floor-1-entry`；
- 固定内容：出生点、抄写员、前段篝火、基础操作提示；
- 视觉：暖褐、余烬橙、纸张米色；
- 行为：整间房为安全区，默认完全揭示；
- 反目标：不摆放怪物、随机战利品、伤害机关和多个意义相同的门。

### 4.2 中央：失名迷宫

- 固定内容：SELECT、WHERE、IS NULL、GROUP BY、HAVING 的课程锚点和 Boss；
- 随机内容：连接走廊、可选支路、补给位置、少量陷阱；
- 视觉：蓝黑石墙、青色 SQL 机关、红色危险物；
- 行为：视野半径缩小，敌对单位和伏击只允许在这里出现；
- 教学：必修路线必须可达；Seed 不得改变课程先后条件。

### 4.3 右侧：登记前哨

- 固定房间：`floor-1-rest`；
- 固定内容：后段篝火、Boss 前整备和通往中央迷宫的单一门；
- 视觉：冷金、灰石和已经熄灭的登记灯；
- 行为：整间房为安全区，抵达后完全揭示；
- 解锁：完成 `GROUP BY` 后，迷宫一侧的知识门允许进入；
- 反目标：不复制抄写员、图鉴、出生教学和左侧家园全部功能。

## 5. 进入迷宫状态机

| 当前状态 | 输入 | 结果 |
|---|---|---|
| 安全区内 | 向迷宫方向移动 | 第一次拦截移动并打开确认框 |
| 确认框 | 进入迷宫 | 关闭框、确认本层进入、重放被拦截的移动 |
| 确认框 | 暂不进入 / ESC | 关闭框，玩家位置不变 |
| 已确认 | 再次从任一安全区进入 | 直接移动，不重复打断 |
| 重开新 Run | 首次进入 | 重新询问 |

确认框只说明迷宫内视野降低、会遭遇怪物，以及封存机关仍在黑暗中运转。不得提前直说机关
伤害数值；它也不是剧情长文。推荐短文案：

> 失名迷宫内视野会缩小，封存机关仍在黑暗中运转。进入后可原路返回安全区。

## 6. 视野规则

- 左右安全区：本房间所有可行走格永久明亮；
- 中央迷宫当前基线为曼哈顿半径 4；V1.1 改为半径 3，约从 41 个明亮格收缩为 25 个；
- 已探索但离开当前视野的格：以约 55% 黑雾保留地图记忆；
- 未探索格：维持约 94% 黑雾；
- 门、陷阱、怪物和掉落遵循相同的可见性，不允许隔墙透视。
- 传送宝箱落点按半径 3 立即揭示；管理员全图模式不应用黑雾。

## 7. 陷阱规则

第一层每个 Seed 生成 2 个“档案切纸轮”灰盒陷阱：

- 只放在中央迷宫走廊；
- 与出生点、安全区、课程锚点、知识门、篝火、捷径端点至少相隔 2 格；
- 不占唯一窄路，优先选择至少有 3 个可行走邻格的位置；
- 踏入时直接造成 1 点伤害，先消耗护甲；
- 不打开战斗界面；
- 同一陷阱每次 Run 只触发一次，已触发后变暗；
- 若导致死亡，沿用现有死亡复盘与最近篝火复活流程。
- 进入迷宫和接近机关时不显示“将会掉血”；真正触发后才反馈
  `档案切纸轮启动，生命 -1`，保证结果可理解但不提前泄露伤害。

## 8. V1.1 宝箱扩展

### 8.1 数量与职责

| 类型 | 数量 | 位置原则 | 结果 |
|---|---:|---|---|
| 普通奖励箱 | 2 | 优先放在合格死路 | 确定奖励或 Seed 稳定奖励 |
| 宝箱怪 | 1 | 中段支路，不占唯一通路 | 按 `E` 直接进入小 Boss 战 |
| 传送宝箱 | 1 | 支路或回环节点 | 先领奖，再传送到合格迷宫格 |

四个宝箱由 Run Seed 派生，同一 Seed 的类型、位置和结果稳定；宝箱之间不能占同一格，也不能与
课程锚点、门、篝火、陷阱、怪物或主线钥匙重叠。

### 8.2 宝箱怪契约

- 外观首先应被读成宝箱，只保留轻微呼吸、锁扣眨动或阴影反常等可观察线索；
- 靠近按 `E` 后立即切入战斗，不先发放奖励；
- 战斗前继续只显示稳定 ID，击败后才恢复简短怪物名字并写入图鉴；
- 血量至少承受约 5 次正确攻击，题目从第一层 `SELECT + WHERE` 复合题起步，但不使用下一层知识；
- 作为小型精英奖励 `3 XP`；撤退或死亡保留已经揭示的宝箱怪状态和本场规则；
- 难度主要来自复合题与阶段数，第一层反击仍不得让满血新手无预告必死。

### 8.3 传送宝箱契约

- 按 `E` 后先完成奖励结算，再播放约 0.7 秒的收束动画；
- 落点必须位于中央迷宫可行走格，且不是 Boss 房、安全区、篝火、陷阱、怪物、门、宝箱或死路；
- 落点与起点建议至少相隔 8 个步行距离，并在当前解锁状态下存在返回主线或安全区的路线；
- 落地后提供 3 个合格移动步的遭遇保护，并按半径 3 揭示周围；
- 候选为空时只发放奖励并明确显示“传送未响应”，不得传入死路或重掷整张地图；
- 目标由 `Run Seed + 宝箱稳定 ID` 决定，刷新页面不能重抽。

## 9. 固定与随机边界

| 固定 | 随机但受约束 |
|---|---|
| 左右安全区位置与尺寸 | 中央房间之间的走廊折线 |
| SQL 课程、前置条件与怪物身份 | 可选支路与死路补给位置 |
| 抄写员、两个篝火、Boss、出口 | 两个陷阱的位置 |
| 宝箱类型数量与落点安全约束 | 四个宝箱的位置、普通箱奖励和传送落点 |
| 右侧知识门的解锁条件 | 装饰物的小范围变化 |

Seed 必须可重放：相同 Seed 产生相同地图和陷阱；不同 Seed 不得破坏主线可达性。

## 11. 验收标准

### 11.1 当前基线

1. 20 个固定 Seed 均能从左安全区抵达所有必修房间、右安全区和 Boss；
2. 新 Run 的两个篝火固定属于 `floor-1-entry` 与 `floor-1-rest`；
3. 怪物、伏击和陷阱不会出现在两个安全区；
4. 首次越过安全边界一定弹确认框，取消不会移动，确认只打断一次；
5. 两个陷阱均可见、可触发、直接扣血且不打开 SQL 战斗；
6. 旧 v11 第一层存档可加载；旧地图按自身序列化拓扑继续运行；
7. 自动化测试、TypeScript 构建和浏览器主路径巡检通过；
8. 目标浏览器内保持 30 FPS，没有随帧创建大量对象或音频节点。

### 11.2 V1.1 新增验收

1. 20 个固定 Seed 均生成 2 个普通箱、1 个宝箱怪和 1 个传送宝箱，且无重叠；
2. 宝箱怪只能由 `E` 触发，使用第一层题目，击败后结算 `3 XP` 并恢复名字；
3. 传送落点在 100 个 Seed 中都不是 Boss 房、死路或不可返回格，刷新不改变结果；
4. 中央迷宫半径 3、安全区全亮、管理员无雾三种状态均有自动或浏览器证据；
5. 陷阱触发前不出现伤害文字，触发后伤害和死亡结果仍有明确反馈；
6. 旧 v11 Run 加载后获得确定派生结果，不需要增加存档版本。

## 12. 风险与取舍

- 48×36 内同时放入两个安全区会压缩中央迷宫，因此优先保证路线辨识与教学节奏，不追求最大面积；
- 右侧门在 V1 由课程进度打开，属于“从深处获得资格”的灰盒表达；正式版可再补拉杆动画；
- 陷阱状态暂不新增存档版本，旧 Run 的陷阱由其保存地图和 Seed 稳定派生；
- 正式美术前先用统一金色交互、青色 SQL、红色危险语义验证可玩性，避免再次堆叠不明装饰。
- 半径 3 会放大迷路风险，因此保留暗色地图记忆，不同步删除路线信标；
- 宝箱怪不采用高反击伤害冒充难度，避免玩家在获得任何生命成长前被不可预期地秒杀；
- 传送失败宁可退化为普通领奖，也不能把玩家送进无法返回的位置。
