# 第七层逐事件叙事脚本：残照索引王苑

> 脚本版本：`v1.1` · 状态：`RUNTIME V1.1 VERIFIED`
>
> 目标时长：首次 `35–50` 分钟
>
> 课程：`B-Tree / 复合索引 / 覆盖索引 / 索引失效 / EXPLAIN / 优化审计`

## 0. 本层职责

第七层不把性能等同正义。玩家学习索引和执行计划，同时发现王城曾用“最快路径”长期绕开不愿面对的
历史记录。

本层问题：

> 当前路径找不到一条记录时，它是否已经不存在？

本层结论：

> 不是。索引改变访问路径，不改变事实；完整扫描仍能证明被绕开的历史存在。

## 1. 空间结构

| 区域 | 两条路 | 课程 | 提交结果 |
|---|---|---|---|
| 水晶枝径 | 完整扫描长路 / 主键晶枝短路 | B-Tree、复合索引 | 索引枝按最左前缀展开 |
| 盘根回廊 | 回表湖路 / 覆盖镜湖 | 覆盖索引、失效改写 | 湖面直接返回结果，缠根退去 |
| 索引树心 | 黑箱树根 / 可读执行计划 | EXPLAIN、路径比较 | SEARCH、SCAN、排序节点显形 |

完整扫描长路始终保留，不能在索引短路点亮后删除。玩家必须能直观看到“慢但完整”和“快但有前提”
同时存在。

## 3. 抄写员

入层：

> “这条长路很慢，却能看见每一页。”
> “那条晶枝很快，也决定了哪些记录永远不会被经过。”

盲索引花园：

> “第四层那段签名来自最后的档案官。”
> “我保存了它，却把通向它的路径藏了起来。”

层结论：

> “最快的路径不是唯一的事实。”
> “现在我们带着完整扫描和索引证据，一起去见那位档案官。”

## 4. SQL 密文：最优叶密文门

密文要求从多个 `realm` 中选择各自代价最低且结果健康的叶节点。题面必须说明分区字段、排序字段、
输出字段和并列处理，不允许只写“找最优”。

成功后：

- 树心侧门永久开放；
- 晶核由青色变金；
- 《失名录》记录“优化选择没有删除其他候选路径”；
- 不提前判定 Boss 或层完成。

现场证据：

- `f7-all-realms-present`：按 realm 统计三类记录，证明索引路径没有删去其他领域。
- `f7-crystal-plan-candidates`：显式写出过滤、排序和 `LIMIT 2`，把选择路径变成可复核证据。
- 证据结论只描述本游戏的 SQLite 夹具，不外推为所有数据库的固定计划。

## 5. 盲索引花园与水晶甲

前置：`B-Tree / 复合索引 / 覆盖索引`。入口是一面没有索引路标指向的花墙，玩家通过完整扫描长路
抵达。

确定奖励 `crystal-armor`：

- 视觉：透明晶肩、折光边线、冷暖双色反射。
- 功能：普通护甲承伤，不提供“查询加速”数值。
- 主题：被短路绕开的东西仍值得被携带。

## 6. 验收

- 扫描长路始终可见、可走或可明确回访，不能在课程完成后消失。
- 执行计划显示真实结构，不以设备毫秒数判分。
- 索引失效题明确说明函数、转换或范围条件造成的问题。
- 盲索引花园不是随机入口，不影响主线。
- 金色长阶只在本层完成后激活。
