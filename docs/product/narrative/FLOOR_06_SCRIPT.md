# 第六层逐事件叙事脚本：龙脊回滚工坊

> 脚本版本：`v1.1` · 状态：`RUNTIME V1.1 VERIFIED`
>
> 目标时长：首次 `35–50` 分钟
>
> 课程：`INSERT / UPDATE / DELETE / 约束 / 事务回滚 / SAVEPOINT`

## 0. 本层职责

第六层是全作第一次写操作层。所有玩家语句都在一次性 SQLite 副本执行并在判定后丢弃；世界表现
可以展示候选状态，但不能声称修改了正式存档数据库。

本层问题：

> 写入是否只能在盲目提交与全部撤销之间二选一？

本层结论：

> 不是。明确目标、约束、隔离副本、事务和保存点让改变能够先验证，再决定提交或局部撤销。

## 1. 地图

| 区域 | 视觉 | 课程 | 世界状态 |
|---|---|---|---|
| 岩浆孵化工坊 | 玄武岩、铜槽、低亮熔光 | `INSERT / UPDATE` | 孵化副本由原始→写入→定向更新 |
| 龙晶修复洞 | 蓝绿晶体、清理槽、白色约束线 | `DELETE / CHECK` | 指定重复项移除，无效候选被拒绝 |
| 回滚山巅 | 雪线、红蓝双轨、保存点祭台 | `BEGIN / ROLLBACK / SAVEPOINT` | 候选轨回归原轨，正确段被保留 |

地图上同时展示“原始”和“候选”两条轨，避免把回滚误解成时间倒流。王室升降台只在最终结算后激活。

## 2. 事件顺序

| 顺序 | ID | 触发 | 提交结果 |
|---:|---|---|---|
| 1 | `f6-story-change-can-return` | 入层 | 提出“先改变，再证明能回来” |
| 2 | `f6-row-inserted` | `f6-insert` | 孵化副本新增字段完整记录 |
| 3 | `f6-row-updated` | `f6-update` | 只有 WHERE 锁定行改变 |
| 4 | `f6-duplicate-targeted` | `f6-delete` | 只有指定重复鳞片移除 |
| 可选 | `f6-story-rookery` | 隐藏门开启 | 审计痕迹与龙鳞甲 |
| 5 | `f6-constraint-protected` | `f6-constraint` | 无效候选被约束拒绝 |
| 6 | `f6-transaction-rolled-back` | `f6-transaction` | 候选桥回到原始状态 |
| 可选 | `f6-story-cipher` | 密文正确 | 龙巢侧门永久开 |
| 7 | `f6-savepoint-validated` | `f6-savepoint` | 只撤销错误段 |
| 8 | `f6-story-safe-change` | 击败 `ID #061` | 古龙巢验证，升降台激活 |

## 3. 抄写员

入层：

> “我曾以为最安全的答案是全部回滚。”
> “这里要求我们先改变，再证明自己能安全回来。”

育龙室：

> “这些生命没有被提交，却留下了完整的审计轨迹。”
> “回滚保护了现在，也不能假装候选从未存在。”

层结论：

> “不是盲目提交，也不是抹掉所有候选。”
> “先隔离、再验证、保留回滚——这是一条真正能前进的路。”

## 4. SQL 密文：逆鳞密文门

密文只接受只读预演，不要求玩家在高风险侧门里写数据。题目让玩家用现有表证明每个分区将受影响的
行数和目标边界；成功后才开放龙巢旁路。

这条限制是产品边界：

- 写操作只属于本层课程沙箱。
- 地图密文统一使用 `executeSelect`，不会污染 `repair_queue`。
- 正确只开路；错误反噬 1 点；空输入和退出无代价。

现场证据：

- `f6-duplicate-candidates`：删除前列出两条候选，明确只能处理指定 id。
- `f6-baseline-restored`：回滚后重新读取五条基线，证明课程写入没有污染正式教学数据。
- 主框展示的是只读证据；玩家写操作仍只在一次性沙箱中执行。

## 5. 隐藏育龙室与龙鳞甲

前置：`INSERT / UPDATE / DELETE` 三项都完成。室内的“未提交生命”是审计记录，不宣称被回滚候选
仍是活体 NPC。

确定奖励 `dragon-armor`：

- 视觉：鳞片肩甲、低亮青铜边、龙脊背线。
- 功能：护甲生命优先承伤；不提高 SQL 判定宽容度。
- 叙事：证明玩家愿意携带改变留下的审计责任。

## 6. 验收

- 任何课程执行后正式 SQLite 教学数据不被永久修改。
- 原始轨与候选轨在视觉上可同时辨认。
- `ROLLBACK` 与 `SAVEPOINT` 的地图结果不同。
- 约束失败显示明确原因，不以怪物神秘能力代替数据库概念。
- 管理员预设覆盖孵化副本、育龙室、密文门、古龙完成态。
