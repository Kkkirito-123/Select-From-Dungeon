## 8. 逐层验收卡

### 8.1 第一层：地下余烬档案

核心动词：调查、排水、回返。

- 已有：水轮、退水、无名宿舍、恢复回执、登记厅、升降机、两处篝火、隐藏旧库；
- 已有：`SELECT/FROM → WHERE → IS NULL → GROUP BY → HAVING` 的世界状态链；
- 缺口：抄写员从入口到门、档案室和升降机的行动没有完整运行时编排；
- 缺口：长剧本中的镜头、音乐和证据动作仍退化为短文字卡；
- 验收：不看 HUD 可识别余烬档案；击败前只见 ID；回访旧库和登记厅有不同状态。

### 8.2 第二层：月潮群岛

核心动词：航行、选岛、改潮。

- 已有：水域、浅滩、沉水村落、根桥、船闸、灯塔、区域首领与北岸渡船；
- 已有：排序浮标、去重水纹、INNER/LEFT JOIN 桥与村落状态；
- 缺口：体验配置四区、生态运行时三区，需要一个地区名称与拓扑真源；
- 缺口：区域 Boss 场景可以触发战斗，但地标调查和提示不统一；
- 验收：退潮前后路径显著不同；船闸开启后 2–3 分钟内产生真实折返价值。

### 8.3 第三层：白霜墓原

## 11. 风险与取舍

| 风险 | 取舍 |
|---|---|
| 八层同时精修造成范围失控 | 先清全局 P0，再按 F1–2、F3–4、F5–6、F7–8 四批验收 |
| 跨层回访破坏存档与课程拓扑 | 使用显式临时回访状态和返回锚点，不复用普通换层流程 |
| 每层独立机制导致代码爆炸 | 共享状态机和交互协议，每层只增加一个主要机制与一个惊喜 |
| 身份谜题与 SQL `name` 教学冲突 | 普通课可在战斗阶段按规则揭示；探索密文一律以 `id` 和证据列定位 |
| 正式音频扩大包体 | 每层按需加载少量压缩循环，失败时才回退程序乐谱 |
| 美术资源形成拼盘 | 统一像素网格、描边和色板，只为关键地标增加楼层专属轮廓 |
| 自动测试变慢 | 保留大样本压力测试，拆出慢测配置与独立超时，不降低 Seed 覆盖 |
