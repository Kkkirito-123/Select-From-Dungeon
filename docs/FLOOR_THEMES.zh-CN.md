# SQL 魔王城八层地图与美术蓝图

状态：**`v0.7.0` 已实现八层主题/拓扑契约和前两层生态 Tile；第三至八层地图尚未实现**
关联课程：[八层课程蓝图](CURRICULUM.zh-CN.md)
主要用户：玩家、关卡设计者、像素美术与前端实现者

[English](FLOOR_THEMES.md) | **简体中文**

## 1. 目标

让每一层拥有独立的地图身份，而不是复用同一张迷宫后只替换背景色。玩家即使隐藏 HUD，也应该
能够从地砖、墙体、拓扑、环境元素、地标和 Boss 房轮廓判断自己在哪一层。

地图变化必须服务课程：

- 第一层简单、温暖、方向明确，让新手把注意力放在 SQL；
- 中间楼层逐渐增加结构复杂度，并让地图形状隐喻当前知识；
- 第八层不再像普通随机迷宫，而是一条通向黑金王座的终局路线；
- 视觉差异不能换来更多死路、无意义折返或持续粒子消耗。

## 2. 全局美术与地图原则

### 2.1 每层必须同时改变五个维度

1. **元素**：火、蒸汽、雷电、镜影、星轨、熔岩、生命数据、王座虚空。
2. **材质**：石、铜、悬桥、镜面、天文金属、黑铁、树根晶体、黑曜石与黄金。
3. **宏观拓扑**：环路城堡、汇聚钟楼、关系群岛、嵌套地窟、分区环塔、回滚工厂、B+ 树分支、
   王座长轴。
4. **地标**：入口、主学习区、捷径、预习门和 Boss 房都拥有本层专用轮廓。
5. **环境动态**：每层只选择一到两种低成本离散动画，不叠加全屏滤镜和无限粒子。

只换色板而不改变地图结构，不算完成一层主题。

### 2.2 学习优先

- 必修学习点之间的路径距离目标为 20–55 个可行走 Tile。
- 无奖励的死路最长不超过 8 格；有宝箱或故事的可选死路最长不超过 12 格。
- 每个宏观学习区至少有两个出口或一个通关后开启的回程捷径。
- 玩家离开战斗后，下一处主要地标应在 30 秒内可发现；随机遭遇不能用来掩盖空洞寻路。
- 锁定知识门必须同时显示图标、材质变化和文字原因，不能只用颜色区分。
- 小地图反映本层材质和拓扑，但仍然只显示已经探索的位置，不提供点击传送。
- 环境火焰、熔岩和雷电在首版只作为视觉语言，不造成被动伤害，不在玩家输入 SQL 时干扰。

### 2.3 元素递进

```text
生活火焰
  → 机械热能
  → 雷电关系
  → 幽灵镜火
  → 星光与时间
  → 熔岩与冷却
  → 树根与数据生命
  → 黑金王火与虚空核心
```

第一层的火焰提供安全感和方向；第六层把火焰升级为危险熔炉；第八层再把火焰变成象征权力的
王座火。这样可以保留贯穿全局的元素线索，同时让每一层有自己的含义。

## 4. 各层地图定义

### 第一层：余烬青石城

**课程对应**：单表查询。
**体验目标**：安全、清楚、温暖；玩家优先学会移动、遭遇和输入 SQL。

| 维度 | 设计 |
|---|---|
| 色板 | 炭黑、青灰石、暖橙、旧金、固定青色 SQL 高亮 |
| 材质 | 大块青石、木门、铁栅、少量苔藓、砖砌火盆 |
| 拓扑 | 宽走廊、短环路、少量可选侧室；不使用隐藏门和长单出口通道 |
| 环境 | 两帧火炬、缓慢上升的少量方形余烬、火盆明暗切换 |
| 地标 | 城门、Schema 档案厅、过滤回廊、空值墓室、排序岗楼 |
| 捷径 | 击败第二只必修怪后打开一条返回入口的石门 |
| 预习门 | 门上出现分组柱形纹章，后方可见第二层黄铜光 |

Boss 房是半圆形审判厅。查询监视者位于中央石台，后方排列五个火盆；每完成一个查询阶段便点亮
一个火盆。通关后火盆向中央收束成自动传送门。

这一层的火焰不使用动态光照。亮暗只通过地砖色块和两帧动画表达，保持复古像素质感。

### 第二层：蒸汽聚合钟楼

**课程对应**：聚合函数与分组。
**体验目标**：让“许多明细汇成少数组”成为可见的地图结构。

| 维度 | 设计 |
|---|---|
| 色板 | 深褐、黄铜、炉火红、蒸汽白、仪表青 |
| 材质 | 铆钉铜板、齿轮墙、管线、压力表、炉膛砖 |
| 拓扑 | 4–6 条辐条走廊汇入中央钟轴；侧路代表明细，中心代表聚合 |
| 环境 | 四帧慢速齿轮、离散蒸汽团、压力表指针跳格 |
| 地标 | 计数机房、平均值水箱、分组平台、HAVING 阀门 |
| 捷径 | 每完成一个分组节点，中央轴开启对应辐条的双向升降台 |
| 预习门 | 两块铜板之间出现关系链，远处可见第三层蓝色电弧 |

Boss 房是一张圆形钟面。不同分组占据不同扇区，达到 `HAVING` 阈值的扇区亮起。聚合 Boss 被击败
后，所有指针归零并组成关系传送门。

蒸汽只在事件触发时生成短寿命色块，不持续运行粒子系统。

### 第三层：雷鸣关系桥城

**课程对应**：连接与集合。
**体验目标**：让表之间的关系变成真实的桥。

| 维度 | 设计 |
|---|---|
| 色板 | 深海军蓝、电青、紫罗兰、雨灰、白色闪电 |
| 材质 | 悬浮石台、金属桥、绝缘柱、风暴云层、关系节点 |
| 拓扑 | 多座资料岛通过桥相连；不同 JOIN 节点使用不同桥型 |
| 环境 | 两帧电弧、远景雨线、桥柱离散脉冲 |
| 地标 | 怪物岛、房间岛、装备岛、自连接镜桥、集合双桥 |
| 捷径 | 正确连接两张表后，桥成为永久双向路线 |
| 预习门 | 桥下出现嵌套方框纹章，通向第四层紫黑地窟 |

`INNER JOIN` 桥两端必须都激活才出现；`LEFT JOIN` 区保留左侧完整平台，右侧故意有一个可见缺口；
`UNION` 使用两条平行桥在出口汇合。地图隐喻只能辅助理解，终端仍提供完整关系字段。

Boss 房由三座平台组成，分别代表房间、怪物和装备，三条关系桥汇入中央雷鸣主核。

### 第四层：镜影子查询地窟

**课程对应**：子查询、`EXISTS` 与 CTE。
**体验目标**：表现“查询里面还有查询”，但不能退化成让玩家迷路的套娃迷宫。

| 维度 | 设计 |
|---|---|
| 色板 | 墨黑、深紫、银灰、幽火绿、镜面蓝 |
| 材质 | 黑石、碎镜、浅水反射砖、墓室拱门、幽火灯 |
| 拓扑 | 大房间包围小房间的嵌套结构，每个内层至少有两条可理解路线 |
| 环境 | 镜面双帧闪光、幽火轻微上下跳格、静态倒影图案 |
| 地标 | 标量镜室、空值陷阱池、存在性墓门、CTE 档案环 |
| 捷径 | 完成内层查询后，镜墙变成通往外层主路的透明门 |
| 预习门 | 镜面浮现窗口分区环，连接第五层星空 |

Boss 房使用三个同心矩形。玩家每完成一个查询阶段，就从外层进入一层；中央镜像议会不会要求
回走已经解决的通道。

镜面效果使用交替 Tile 和固定高光，不使用实时反射、模糊或后处理 Shader。

### 第五层：星轨窗口观测塔

**课程对应**：窗口函数。
**体验目标**：把分区、顺序、前后行和窗口 Frame 变成环形星轨。

| 维度 | 设计 |
|---|---|
| 色板 | 午夜蓝、靛紫、冰蓝、淡金、星光白 |
| 材质 | 天文金属、玻璃窗格、星盘地砖、细金属栏杆、风塔石 |
| 拓扑 | 多个分区环廊围绕中央竖井；环内顺序明确，环间有短连接 |
| 环境 | 星点离散闪烁、时间环逐格旋转、窗外慢速云带 |
| 地标 | PARTITION 圆厅、排名台阶、前后行双塔、累计轨道 |
| 捷径 | 完成一个分区后，中央竖井电梯直达该环入口 |
| 预习门 | 星盘切换为事务状态图，向第六层投下红色熔炉光 |

Boss 房是一张大星盘，被清晰划分为多个扇区。排名、并列与累计值通过扇区地砖逐段亮起，但不会
替代 SQL 结果表。

所有星点共享一个低频节拍，避免每颗星拥有独立 Tween。

### 第六层：熔火回滚铸造厂

**课程对应**：写操作与事务。
**体验目标**：让“修改、失败、回滚、提交”拥有可见的前后状态。

| 维度 | 设计 |
|---|---|
| 色板 | 黑铁、熔岩橙、警告红、冷却青、炉渣灰 |
| 材质 | 铁板、传送带、熔炉砖、冷却管、检查阀、保存点信标 |
| 拓扑 | 生产环线；每个 SAVEPOINT 是一个可回到主线的安全节点 |
| 环境 | 三帧熔岩、锻锤跳格、冷却蒸汽事件、警告灯明暗切换 |
| 地标 | INSERT 投料口、UPDATE 修复台、DELETE 清理槽、约束检测门 |
| 捷径 | 执行正确回滚后，废料管道翻转成回到最近保存点的通道 |
| 预习门 | 炉壁长出绿色索引根系，通向第七层 |

Boss 房分为“事务前”和“事务后”两条平行状态带，中间是保存点控制台。错误操作让后状态带出现
红色差异，但永久世界不会改变；正确回滚后差异砖恢复。

熔岩只是 Tile 动画，不使用实时热扭曲。首版不加入持续地形伤害。

### 第七层：翠晶索引森林

**课程对应**：索引与执行计划。
**体验目标**：让 B+ 树、叶节点和访问路径成为可探索结构，同时保持方向清楚。

| 维度 | 设计 |
|---|---|
| 色板 | 墨绿、青绿、晶体青、象牙白、索引金 |
| 材质 | 巨树根、石碑、数据晶体、叶节点平台、发光路径 |
| 拓扑 | 从根节点向中间节点和叶节点分支；叶层之间存在水平链路 |
| 环境 | 晶体脉冲、数据叶片短距离飘落、根系光点逐格传播 |
| 地标 | 联合索引岔路、覆盖索引树冠、失效沼地、执行计划石碑 |
| 捷径 | 正确索引方案会点亮更短访问路径，但原路线仍然可达 |
| 预习门 | 根系包围黑金王门，门后出现第八层红金火光 |

玩家不能因为选择了“较差索引”而被迫走很长的真实路。长短路径主要是视觉反馈，课程判定仍来自
稳定计划指标。

Boss 房是一棵巨型古树的根部。不同计划节点沿根系亮起，临时排序和全表扫描使用明显但非闪烁的
警告纹理。

### 第八层：黑金数据王座

**课程对应**：数据库八股终局。
**体验目标**：从“探索楼层”转向“进入王城、穿过七翼、登上王座”的终局仪式感。

| 维度 | 设计 |
|---|---|
| 色板 | 黑曜石、暗红、王室紫、旧金、核心青白 |
| 材质 | 黑曜石长砖、金边柱、红色帷幔、王火盆、数据石碑 |
| 拓扑 | 固定中央长轴连接七个知识翼；Seed 只变化侧翼细节，不改变王座推进方向 |
| 环境 | 王火两帧跳动、帷幔轻微摆动、窗外远景雷光、王座核心脉冲 |
| 地标 | MVCC 档案翼、锁链庭院、隔离审判室、建模厅、复制双塔、分片门、安全回廊 |
| 捷径 | 每完成一个知识翼，就开启返回中央长轴的金色拱门 |
| 终局门 | 七个楼层徽记全部点亮后，王座大厅大门沿中线打开 |

第八层不使用完全随机的迷宫。中央长轴、七个知识翼和王座大厅位置固定，Seed 只改变支线房间、
装饰、可选奖励和随机复习遭遇，保证终局方向感。

Boss 房采用三段式构图：

1. **长阶**：展示前七层徽记，回顾已经掌握的知识；
2. **审判台**：进行查询、执行计划和并发时间线阶段；
3. **黑金王座**：数据库魔王与青白数据核心重叠，完成最终修复后王座从中间裂开。

终局动画使用 Tile 替换、相机轻震和少量矩形碎片，不使用全屏视频或高成本 Shader。

## 5. 楼层过渡

每层 Boss 奖励领取后自动出现传送门，不要求玩家再次寻找出口或打开菜单。

传送门遵守统一的 1–2 秒节奏：

1. 当前层的主元素向门中心收束；
2. 下一层的主色和地标剪影短暂出现；
3. 玩家、等级、装备和课程档案保持；
4. 新层入口先显示层名、学习目标和新增语法范围；
5. 恢复操作后给予短暂安全步数。

| 过渡 | 视觉 |
|---|---|
| 1 → 2 | 余烬汇成黄铜齿轮 |
| 2 → 3 | 齿轮放电，展开关系桥 |
| 3 → 4 | 闪电击碎为镜片 |
| 4 → 5 | 镜片排列成星轨窗口 |
| 5 → 6 | 星轨坠入熔炉并亮起保存点 |
| 6 → 7 | 冷却后的炉渣长出翠绿根系 |
| 7 → 8 | 根系推开黑金王门 |

## 7. FC 式性能预算

地图风格通过小素材和规则变化实现，不依赖显卡特效。

| 项目 | 预算 |
|---|---|
| 基础 Tile | 继续使用 16×16 整数像素网格 |
| 色板 | 每层 8–12 个主色，SQL/危险/奖励的语义色跨层保持 |
| 地形 | 一个静态 Tile 层或合批 Graphics，不为每块墙创建独立 Tween |
| 动画环境 | 视口内最多 16 个动画装饰，离开视口暂停 |
| 环境碎片 | 同屏最多 24 个池化矩形，短寿命，不无限累计 |
| 火焰/熔岩 | 2–3 帧 Tile 动画，不使用动态光照和热扭曲 |
| 镜面/星空 | 交替 Tile 与共享节拍，不使用实时反射和全屏滤镜 |
| 天气 | 低密度线条或背景层，页面失焦时完全暂停 |
| 素材 | 优先共享几何与小图集，不加载高分辨率背景视频 |
| 更新 | 地形不进入逐帧逻辑；只更新视口内角色和少量环境对象 |

目标不是口头声称“零性能”，而是留下可重复证据：

- 桌面目标 60 FPS，低端手机目标稳定 30 FPS；
- 连续移动 10 秒没有明显长帧；
- 页面隐藏后地图、天气和音乐停止推进；
- Reduced Motion 下停止装饰 Tween、碎片和震屏，但保留地标、状态和 Tile 差异；
- 新增一层不能让初始包一次加载八层全部专用大素材；
- 性能不达标时先删除装饰动画，不削弱 SQL 反馈和可读性。

## 8. 可访问性

- 不只依靠颜色区别楼层：墙体纹理、地标轮廓和拓扑必须不同。
- 门锁同时使用图标、文字和材质，不用红绿二色作为唯一信号。
- 火焰、闪电和星点不高频闪烁；重要提示避免超过每秒三次亮暗变化。
- SQL 文本、血量、提示和交互按钮保持跨层固定布局，不随主题变得难读。
- Reduced Motion、静音和窄屏模式仍能通过静态图形理解每层身份。
- Boss 房的视觉反馈不能遮挡终端、字段提示或查询结果。

## 9. 验收标准

### 地图与学习

- 隐藏 HUD 后，从一张入口截图可以识别八个楼层；
- 每层的主元素、材质、拓扑、地标和 Boss 房至少有四项不同；
- 第一层入口可见火炬或火盆，最终层明确显示黑金长轴和王座；
- 必修点间距、死路长度和回程捷径符合全局预算；
- 环境危险在首版不造成被动生命损失；
- 地图隐喻辅助课程，但完整字段和目标仍由终端明确展示。

### 自动化

- 每个拓扑策略对固定 Seed 保持确定性；
- 至少 500 个 Seed 通过必修区可达、门锁不可绕过、Boss 路径和死路上限检查；
- 第八层固定中央长轴与王座，Seed 只改变允许变化的侧翼内容；
- 主题切换不改变课程 `lessonId`、掌握度和确定奖励；
- Reduced Motion 和页面隐藏状态停止装饰更新。

### 浏览器

- 桌面和 390×844 窄屏各验收一次入口、必修区、Boss 房和传送门；
- 实测连续移动、环境动画、战斗切换和返回地图；
- 记录 10 秒帧时间与活动对象数量；
- 检查火焰、雷电、镜面、星空、熔岩、森林和王座均无控制台错误；
- 不用“构建成功”替代视觉、寻路和性能验收。

## 10. 分阶段交付

1. **主题数据契约 PR**：定义 `FloorTheme` 和八种拓扑策略，不改变当前地图。
2. **共享 Tile 与预算 PR**：建立小色板、视口动画和 Reduced Motion 基线。
3. **第一层主题 PR**：先实现余烬青石城并完成性能验收。
4. **第二、三层 PR**：分别实现聚合钟楼和关系桥城，不合并成一次大改。
5. **第四、五层 PR**：实现嵌套地窟和分区环塔。
6. **第六、七层 PR**：实现回滚工厂和 B+ 树森林。
7. **第八层王座 PR**：单独实现固定终局长轴、七翼和王座 Boss 房。

每个楼层 PR 都必须同时包含地图截图、Seed 可达测试、窄屏检查、性能记录和回滚方式。

## 11. 不做什么与风险

### 当前文档不做

- 不在本 PR 中实现 Tile、地图生成器、动画、美术、音乐或新楼层。
- 不复制其他游戏的地图、美术、Boss 房或音频素材。
- 不使用高分辨率视频、动态灯光、实时反射和全屏 Shader。
- 不让视觉机关替代 SQL 课程，也不让地图危险在输入 SQL 时偷袭玩家。

### 风险与取舍

| 风险 | 取舍 |
|---|---|
| 八层专用素材扩大包体 | 共享 16×16 几何，按楼层延迟加载小图集 |
| 每层拓扑不同增加生成器复杂度 | 共用可达性与门锁校验，只替换宏观策略 |
| 地图隐喻变成解谜负担 | 终端继续明确给出任务、完整字段和关系 |
| 火焰与天气消耗性能 | 使用少量 Tile 帧和池化色块，失焦与离屏暂停 |
| 最终层随机性破坏王座仪式感 | 固定中央长轴与王座，只随机侧翼细节 |
| 视觉主题影响可读性 | HUD 和 SQL 语义色保持稳定，主题只进入世界层 |
