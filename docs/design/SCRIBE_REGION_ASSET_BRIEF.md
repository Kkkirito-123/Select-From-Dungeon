## 1. 本次目标

为叙事探索改造建立第一批可讨论、可试听、可继续像素化的原创素材：

1. 确立篝火引导者“抄写员”的情绪与视觉方向；
2. 把第一层从传统随机迷宫改造成紧凑、环绕、能开捷径的连续区域；
3. 用两首原创程序化音乐建立“抄写员”和第一层的听觉身份；
4. 留下生成提示词、尺寸、音频参数、许可证和已知偏差，避免概念图被误当成正式资产。

## 2. 用户与干系人

| 角色 | 需要从素材中确认什么 |
|---|---|
| 玩家 | 抄写员是否值得信任；地图是否想探索；音乐是否温暖但不喧宾夺主 |
| 游戏策划 | 人物功能、路线节奏、捷径回报和区域叙事是否一致 |
| 美术 | 轮廓、色板、地标、场景温度和运行时像素化边界 |
| 音频 | 两个主题的动机、速度、音色、循环长度和动态关系 |
| 工程 | 32 px 网格、30 FPS、零第三方采样和低负载 Web Audio 的接入边界 |

## 3. MVP 范围

- 一张抄写员三姿态角色概念图；
- 一张第一层连续区域概念图；
- 两首单循环、单声道、22,050 Hz、16-bit PCM WAV 试听；
- 一份可重复运行的本地 Node 音频生成脚本与 SHA-256 清单；
- 一份素材索引与完整生成提示词。

## 4. 本次不做

- 不把概念图直接当作 Phaser Sprite Sheet 或 Tilemap；
- 不修改当前 `ArcadeAudio`、地图生成、篝火交互、剧情状态或存档结构；
- 不制作八层完整角色换装、隐藏区域、Boss、怪物、武器与防具素材；
- 不让抄写员代答 SQL，也不把她设计成恋爱、宗教或无条件赞美型角色；
- 不提交、推送、创建或合并 PR。

## 5. 核心情绪命题

> 魔王城可以寒冷、残缺、充满错误；抄写员是其中唯一稳定的温暖。

“唯一的温暖”不是把她写成万能保姆，而是形成三项稳定承诺：

1. **她记得。** 玩家死亡后遗失本场战斗状态，她仍记得本层学过、错过和反复卡住的知识；
2. **她诚实。** 她会温和指出错误，不假装失败没有代价，也不会直接给完整答案；
3. **她等待。** 玩家可以离开、探索、失败，再回到当前篝火继续，不因操作慢或回答错误被嘲讽。

她的温暖必须依靠行为积累，而不是靠大量煽情台词。建议每次对话只做一件事：欢迎、复盘、
校准或提示方向。

## 6. 角色设计：抄写员

### 6.1 功能定位

| 场景 | 她做什么 | 她不做什么 |
|---|---|---|
| 第一次遇见 | 解释篝火、记录与复盘的关系 | 一次讲完世界观 |
| 在此休息 | 确认当前复活点，提供一句与本区有关的观察 | 免费清空所有风险 |
| 答案复盘 | 按“现象 → 概念 → 最小提示”回看本层错误 | 直接粘贴完整 SQL |
| 能力校准 | 承担升级或长期能力解释 | 用神秘仪式替代清楚说明 |
| 死亡回归 | 接住失败情绪，再指出本层最值得重试的一点 | 嘲讽、说教或重复长教程 |

### 6.2 视觉语言

- 成年女性，双眼可见，平静近乎微笑；
- 暖米白短档案外套、深靛蓝内层、低帮实用靴；
- 输入光标形发夹、折叠记录板、两三张无字索引页；
- 篝火金色轮廓光是主温度，青绿色记录光只作辅助；
- 扫描线异常只出现在衣角和记录页，不把她画成幽灵；
- 不使用兜帽、眼罩、黑色拖地长袍、祈祷姿势、灯笼杖、王冠或武器。

概念图：
[scribe-character-concept-v1.png](./assets/region-01/scribe-character-concept-v1.png)

### 6.3 后续运行时 Sprite 约束

概念图不能直接缩小投产。正式 Sprite 应人工重新像素化：

| 项目 | 规格 |
|---|---|
| 单帧画布 | `32 × 40 px` RGBA |
| 实际人物轮廓 | 最大约 `22 × 31 px` |
| 脚底基线 | `y = 35` |
| 世界显示倍率 | `1×`，关闭插值 |
| Sprite Sheet | `256 × 120 px`，8 列 × 3 行 |
| 动画 | 待机 4、交谈 4、加载成形 6、校准 6，共 20 个有效帧 |
| 方向 | 固定正面略偏三分之四；她不在地图上行走 |

建议不透明色限制为 9 种：
`#14161D`、`#E8DFC7`、`#B8AE96`、`#78C9B8`、`#91E3D1`、
`#3D5078`、`#6A7FAC`、`#7F5A87`、`#D7AD55`。

## 7. 第一层区域设计

### 7.1 一条主线、两个回环

```mermaid
flowchart LR
  A["出生篝火 / 城门登记厅"] --> B["排水渠 / 水轮"]
  B --> C["史莱姆池"]
  C --> D["余烬仓库 / 中段篝火"]
  D --> E["地下档案库"]
  E --> F["Boss 门前篝火"]
  F --> G["半圆审判厅"]
  G --> H["休眠传送门"]
  D -. "开启铁水门捷径" .-> A
  E -. "启用货运升降机" .-> D
```

固定结构：

- **恰好 3 个复活篝火**：出生点、仓库/升降机交界、Boss 门前；
- **恰好 2 条捷径**：
  - 入场就看见但打不开的巨大铁水门，从仓库背面开启后回到出生区；
  - 档案库货运升降机，启用后返回中段篝火；
- 主路宽 2–4 格，广场宽 5–8 格；
- 不用一格细路、长直走廊、无意义死路和纯随机迷宫；
- Boss 厅内的五座火盆是场景照明，不是复活篝火。

概念图：
[floor1-region-concept-v1.png](./assets/region-01/floor1-region-concept-v1.png)

### 7.2 概念图的权威边界

概念图只负责色彩、材质、地标密度和空间气质。上方路线图与固定结构才是拓扑契约。
图中墙体、门宽、碰撞、楼梯、火盆数量和房间比例都必须在灰盒 Blockout 阶段重新验证，
不能从 PNG 自动推导正式地图。

## 8. 音乐设计

> `SUPERSEDED`：本节两首 2026-07-24 首轮试听因 25% Pulse、高音与噪声瞬态造成尖锐感，
> 已被玩家否决，只保留为淘汰对照和生成证据。新的权威方向见
> [音乐与地图上升设计圣经](./MUSIC_MAP_ASCENT_BIBLE.md)。

两首预览共享原创“记录动机”，使玩家潜意识感到抄写员属于这座城，但不引用任何现有作品：

`0 → +3 → +7 → +2`

| 曲目 | 抄写员／篝火 | 第一层探索 |
|---|---|---|
| 工作名 | 余烬档案 / Ember Archive | 湿墙回路 / Wetwall Circuit |
| 文件 | [试听 WAV](./assets/region-01/scribe-ember-archive-preview-v1.wav) | [试听 WAV](./assets/region-01/floor1-wetwall-circuit-preview-v1.wav) |
| 情绪 | 安全、亲近、残缺记忆 | 潮湿、好奇、轻微危险 |
| 调式 | A Dorian | D Dorian |
| 速度 | 68 BPM | 84 BPM |
| 循环 | 8 小节，约 28.24 秒 | 8 小节，约 22.86 秒 |
| 音色 | 三角低音、正弦钟声、极轻脉冲、余烬噪点 | 三角低音、25% 脉冲旋律、三角琶音、弱水滴 |
| 动态 | `pp → mp → pp` | `p → mf`，最后一小节抽空回环 |
| 峰值目标 | 不高于 `-6 dBFS` | 不高于 `-4 dBFS` |

正式接入仍应把确认后的音符数据移入 Web Audio，不在游戏包加载这两份 WAV。抄写员对话建议新增
独立 `campfire` 模式，并把区域音乐降至约 55%；战斗音乐始终拥有更高优先级。

## 10. 验收标准

- 角色缩略观察时能与玩家和怪物区分，并首先传达“温柔可靠”而非“神秘祭司”；
- 地图一眼可识别三段区域、主线方向、三处安全点与两条回环；
- 两首试听能正常播放、可循环、没有第三方录音或采样；
- 音频脚本同一输入生成稳定 SHA-256；
- 概念素材不进入 `src/` 与 `dist/`，不增加运行时下载和性能消耗；
- 素材来源、提示词、参数、限制和后续投产方式均可追溯。

## 11. 风险与取舍

| 风险 | 当前处理 |
|---|---|
| 概念图细节远高于 32 px Sprite | 明确要求后续人工重新像素化，不直接缩图 |
| 生成地图看起来完整，容易被误当正式关卡 | 把路线图和固定结构列为唯一拓扑契约 |
| “唯一温暖”滑向恋爱或万能 NPC | 用记得、诚实、等待三项行为约束 |
| WAV 被误接进运行时导致包体增长 | 标记为试听；正式继续程序化 Web Audio |
| 生成式图像出现不一致小细节 | 概念阶段接受，Sprite 阶段逐像素统一 |
| 过早确认抄写员是否已经死亡 | 只保留扫描线暗示，不在首版锁死身份 |
