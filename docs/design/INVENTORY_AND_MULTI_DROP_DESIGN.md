# 装备背包、换装与独立多掉落

> 状态：`v0.4.0` 已实现通用背包，`v0.8.0` 至 `v0.10.0` 已实现八层生态候选
> 范围：记录武器/防具背包、换装和单次多掉落的当前契约

> `v1.1.0` 当前覆盖规则：下文的多装备随机池与精英/Boss 最低掉落数保留为历史设计，不再是
> 运行时事实。可选随机池仅剩自动使用的恢复品（普通 2%、小型精英 5%、区域首领 10%、
> 层主 0%），不会生成战利品包；课程武器、钥匙和明确宝箱仍按固定来源结算。
> 版本顺序与跨系统边界以 [`GAMEPLAY_EVOLUTION_ROADMAP.md`](../GAMEPLAY_EVOLUTION_ROADMAP.md) 为统一入口。

## 1. 本次目标

玩家可以保留多件武器和防具，并在非战斗状态下进行更换。击败怪物后最多展示 3 件不同战利品，每件候选物品单独计算概率，而不是从一个互斥概率表中只抽一件。

## 2. 物品分类

物品分成三类，避免所有内容挤进同一个背包：

### 2.1 装备背包

保存能够反复更换的：

- 武器。
- 防具。

容量确定为 12 格。已经装备的武器和防具显示在独立装备位，不占背包格。

### 2.2 恢复品栏

保存红药、凝胶、水珠、蛙药、修理片等消耗品：

- 共 3 个快捷栏。
- 同名恢复品可以堆叠，单种最多 5 个。
- 恢复品不占装备背包。

### 2.3 关键物品

单独保存：

- 捷径钥匙。
- 楼层钥匙。
- 课程需要的固定证明。

关键物品不占背包格、不能丢弃，也不参与随机装备掉落。
`v0.5.0` 已按此边界实现捷径钥匙：它在中后段保证生成、由玩家按 `E` 拾取，并在背包界面的
独立关键物品区展示；刷新、休息和死亡都不会丢失。

## 3. 装备与更换

玩家拥有两个装备位：

```text
武器位  1 个
防具位  1 个
```

换装规则：

- 探索状态和篝火菜单中可以打开背包。
- 打开背包时暂停玩家移动和怪物巡逻。
- 战斗、SQL 终端、死亡动画和换层过程中不能换装。
- 装备背包中的武器或防具后，原装备自动回到背包。
- 如果背包已满且原装备无法放回，必须先选择丢弃或替换，不能静默删除。
- 换装立即更新 HUD，并显示伤害和护甲生命变化。

### 3.1 丢弃物品

- 普通武器、防具、恢复品和强化物可以丢弃。
- 已装备物品需要先卸下，不能直接从装备位删除。
- 基础武器、捷径钥匙、楼层钥匙和课程必需奖励不能丢弃。
- 丢弃按钮明确说明物品会落在玩家脚下，当前楼层内仍可重新拾取。
- 玩家离开当前楼层后，仍留在地面的丢弃物永久消失。
- 已经发现过的唯一装备即使被永久丢弃，也不会在同一 Run 中重新随机掉落。

装备比较示例：

```text
湖叉
伤害       1 → 2

是否装备？
[装备] [放入背包] [暂不拾取]
```

## 4. 武器差异

第一至六层的武器 MVP 只显示直接伤害，不显示当前没有实际后果的 `I/O 热量减免`。武器类型先负责掉落层级、攻击动画和伤害成长，不提前加入难以解释的伪属性。

| 武器类型 | 早期属性方向 | 示例 |
|---|---|---|
| 剑 | 平衡伤害成长 | 短剑、骨剑、王剑 |
| 弓 | 中等伤害、远程攻击动画 | 猎弓 |
| 长柄 | 中高伤害、穿刺攻击动画 | 湖叉、龙枪 |
| 重武器 | 高伤害、较慢攻击动画 | 铁斧 |
| 法杖 | 中等伤害、法术攻击动画 | 火杖、晶杖、魔杖 |

高伤害武器不能跳过课程怪物规定的最低正确作答次数。

第七层正式学习索引和执行计划后，可以再为晚期武器加入 `查询负载减免`，但必须先确认该数值实际影响的评分或奖励。

## 5. 防具差异

MVP 中防具只提供护甲生命，不加入复杂词条：

- 第一至二层防具：1 点护甲生命。
- 第三至五层防具：2 点护甲生命。
- 第六至八层防具：3 点护甲生命。

换下防具不会删除它。再次装备时，护甲生命不能超过该防具的上限；篝火休息会恢复当前装备防具的全部护甲生命。

## 6. 独立掉落算法

每只怪物拥有一个与生态区域、楼层和等级对应的候选掉落表。候选物品逐项独立计算：

```text
候选物品列表
→ 用 Run 种子 + 楼层 + 怪物 ID + 物品 ID 计算各自结果
→ 每件物品分别判断是否成功
→ 去除同名结果
→ 加入等级保证掉落
→ 最多展示 3 件
```

规则：

- 每个候选物品的概率互不占用其他物品的概率。
- 同一次击败不会出现两个同名物品。
- 同一件唯一武器或防具在整个 Run 中不会再次掉落。
- 恢复品可以在不同战斗重复获得，但同一场最多出现一份同名恢复品。
- 已拥有装备再次命中时，转换为对应强化物，不重新生成同名装备。
- 所有结果由种子稳定决定，刷新、死亡和休息不能重抽。

## 7. 不同怪物的掉落数量

“最多 3 件”是显示上限，不要求所有普通怪每次都掉满，否则背包会快速失去管理意义。

| 怪物 | 最少掉落 | 最多掉落 | 说明 |
|---|---:|---:|---|
| 普通怪 | 0 | 3 | 每个候选物品独立计算 |
| 小型精英 | 1 | 3 | 至少补足一件恢复品或装备 |
| 区域首领 | 2 | 3 | 两件主题保证掉落，第三件独立计算 |
| 固定精英 | 1 | 3 | 必修奖励优先，其余独立计算 |
| 层主 | 2 | 3 | 楼层钥匙不计入三件战利品上限 |
| 最终魔王 | 3 | 3 | 最终奖励，不再生成下一层装备 |

如果独立计算得到超过 3 件：

1. 保留保证掉落。
2. 优先保留概率更低的稀有装备。
3. 再保留当前层恢复品。
4. 超出的成功结果不落地，也不改变剩余结果。

## 9. 去重与转换

### 9.1 同一场战斗

- 一个物品 ID 最多出现一次。
- 同类但不同名称的物品可以同时出现，例如 `水珠 + 修理片`。
- 武器、防具和恢复品可以同时掉落。

### 9.2 整个 Run

唯一武器和防具已经进入背包后，不再掉落同名装备：

- 同名武器成功命中时，转换为 `磨刀石`。
- 同名防具成功命中时，转换为 `修理片`。
- 已达强化上限且不需要修理时，转换为 1 XP。

恢复品不是唯一物品，可以跨战斗重复掉落并堆叠。

## 10. 拾取与满包

战斗结束后只在地面生成一个“战利品包”，打开后显示最多三张物品卡，避免多个掉落物遮挡地图。

- 点击 `全部拾取` 将恢复品放入恢复品栏，装备放入背包。
- 背包未满时不要求逐件确认。
- 背包已满时只对新装备显示“替换哪一件”。
- 未处理的装备保留在原战利品包中，不会因关闭界面消失。
- 离开当前楼层前必须处理仍包含关键奖励的战利品包。

## 11. 存档边界

当前 Run 需要保存：

```text
装备背包
当前装备武器
当前装备防具
恢复品栏及数量
已经获得的唯一装备 ID
未处理的战利品包
每只怪物的独立掉落结果
```

这些内容随死亡和换层保留，新 Run 重置。永久 SQL 学习档案不保存局内装备。

## 12. MVP 范围

`v0.4.0` 包含：

- 12 格装备背包。
- 一个武器位和一个防具位。
- 非战斗状态换装和直接属性比较。
- 三格可堆叠恢复品栏。
- 每项独立概率、同场去重和最多三件掉落。
- 唯一装备跨战斗去重。
- 战利品包与满包替换。
- 普通物品丢到脚下、关键物品禁止丢弃。

## 13. 本次不做

- 不加入商店、出售价格或金币。
- 不加入材料合成、分解树或装备耐久。
- 不加入随机词条、品质颜色或套装。
- 不允许战斗过程中临时换装。
- 不让钥匙占用背包。

## 14. 验收标准

1. 玩家可以保存并切换多件武器和防具。
2. 战斗中不能通过换装规避已经预告的攻击。
3. 每件候选物品独立计算概率。
4. 一场战斗最多显示 3 件不同战利品。
5. 小型精英至少掉落 1 件，区域首领和层主至少掉落 2 件。
6. 同一场战斗不会出现同名物品。
7. 整个 Run 不会再次掉落已经拥有的唯一装备。
8. 背包已满时装备不会静默丢失。
9. 刷新、死亡和休息不能重抽掉落。
10. 所有装备和转换结果都有直接中文说明。
11. 可丢弃物品会先落到脚下，关键物品和基础武器不能丢弃。

## 15. 风险与取舍

- 普通怪若频繁掉落三件物品，会不断打断 SQL 学习，因此只设置上限、不保证掉满。
- 独立概率可能同时命中很多物品，需要明确的三件截断优先级。
- 12 格背包仍可能在后期装满，因此丢弃操作必须可恢复并清楚标记关键物品。
- 第一至六层换装主要是伤害升级和攻击表现；更复杂的查询负载属性推迟到第七层确认。
- 唯一装备不重复掉落可以减少垃圾物品，但需要稳定的强化物转换作为反馈。

## 16. 已确认决定

1. 换装只允许在探索和篝火状态。
2. 普通怪允许 0 至 3 件、精英至少 1 件、Boss 至少 2 件；钥匙另计。
3. 恢复品、强化物与非关键装备使用当前低概率基线，后续通过实际游玩再平衡。
4. 同名武器转换为磨刀石，同名防具转换为修理片。
