# 八层生态怪物与掉落设计讨论稿

> 状态：八层生态怪物、区域首领与通用主题掉落已在 `v0.8.0` 至 `v0.10.0` 实现；
> 按生态来源进一步拆分候选概率仍是讨论稿
> 范围：记录已实现的八层边界与仍未上线的细分候选
> 版本顺序与跨系统边界以 [`GAMEPLAY_EVOLUTION_ROADMAP.md`](../GAMEPLAY_EVOLUTION_ROADMAP.md) 为统一入口。

## 1. 本次目标

让怪物与所在环境一致：湖泊出现水怪，泥沼出现青蛙，森林出现野兽和树妖。每个大型生态区域可以拥有自己的可选区域首领和主题掉落，不再用“每层最多两只精英”限制内容。

## 2. 核心规则

- 怪物由玩家所在生态区域决定，不能跨区域无意义出现。
- 每个生态区域拥有独立的普通怪、小型精英、区域首领和掉落池。
- 小型精英没有每层数量硬上限，由有限遭遇点和逐层概率控制。
- 一个大型生态区域最多设置 1 个区域首领。
- 区域首领是可选 `elite`，奖励 3 XP；层主才是必修 `boss`，奖励 5 XP。
- 区域首领从二阶复合题起步，小型精英仍连续考两道本层基础题。
- 怪物、精英升级和掉落均由种子稳定决定，刷新不能重抽。
- 已击败怪物不会因死亡或篝火休息刷新。

## 3. 怪物生成层次

```text
楼层
→ 当前生态区域
→ 该区域普通怪物池
→ 稳定概率升级为小型精英
→ 固定生态地标中的区域首领
→ 楼层终点的层主
```

例如第二层：

```text
湖泊      → 水怪 / 水蛇 → 巨水蛇 → 湖怪
泥沼      → 青蛙 / 毒蛙 → 大青蛙 → 蛙王
森林      → 蝙蝠 / 猎犬 / 树妖 → 黑猎犬 → 丛林之王（层主）
```

## 4. 八层生态怪物与主题掉落

### 第一层：软泥地窖

第一层保持史莱姆族，不混入骷髅、恶魔等后期生物。

| 区域 | 普通怪 | 小型精英 | 区域首领 | 主题掉落 |
|---|---|---|---|---|
| 排水渠 | 史莱姆、水史莱姆 | 铁史莱姆 | 大史莱姆 | 凝胶、软泥甲 |
| 旧仓库 | 小史莱姆、毒史莱姆 | 铁史莱姆 | 无 | 红药、短剑 |
| 王巢 | 史莱姆 | 铁史莱姆 | 史莱姆王（层主） | 楼层钥匙、短剑 |

掉落效果：

- `凝胶`：立即恢复 1 点护甲生命。
- `红药`：立即恢复 1 点基础生命。
- `软泥甲`：提供 1 点护甲生命。
- `短剑`：第一层基础武器。

## 5. 随机掉落规则

每次击败怪物只生成一个可见“战利品包”，包内最多包含 3 件不同物品，避免多个地面图标遮挡地图。完整背包与算法规则见 [`INVENTORY_AND_MULTI_DROP_DESIGN.md`](./INVENTORY_AND_MULTI_DROP_DESIGN.md)。

### 5.1 普通怪

- 普通怪的每件候选恢复品、武器和防具分别计算概率。
- 单次可以得到 0 至 3 件物品；XP 固定结算，不计入物品数量。
- 下一层武器继续遵守“每层最多出现一件越阶武器”。
- 普通怪和小型精英的数量不设每层两只上限。

### 5.2 小型精英

- 小型精英的每件候选物品也分别计算概率。
- 保证至少 1 件、最多 3 件物品。
- 如果本层已经出现过越阶武器，新的越阶成功结果回退为当前层武器或强化物。

### 5.3 区域首领

- 区域首领保证 2 件主题掉落，第三件独立计算。
- 首次击败时额外获得 3 XP。
- 区域首领掉落不能是楼层钥匙。
- 同一件区域首领奖励不能通过刷新或复活重复获得。

### 5.4 固定精英与层主

- 固定课程精英保证掉落课程需要的确定性奖励或捷径钥匙。
- 层主保证掉落楼层钥匙和层主主题奖励。
- 第八层魔王不再掉落下一层钥匙，而是给出最终通关证明与完整复盘入口。

### 5.5 非关键装备概率基线

以下约束后续生态专属装备候选；恢复品、强化物与所有保证项不变：

| 来源 | 非关键装备候选 | 单项独立概率 |
|---|---|---:|
| 普通怪 | 当前层武器 | 0.5% 至 0.75% |
| 普通怪 | 当前层防具 | 0.5% |
| 普通怪 | 下一层武器 | 0.25% |
| 小型精英 | 当前层防具 | 2.5% |
| 区域首领 | 非保证可选装备 | 7.5% |
| 区域首领 | 下一层武器 | 1% |
| 层主 | 非保证可选装备 | 7.5% |
| 层主 | 下一层武器 | 1.5% |

课程关键奖励、必需武器、捷径钥匙、楼层钥匙和表中明确写为 `100%` 的主题奖励仍然确定获得。
当前运行时已有通用低概率候选池；这张按生态来源细分的表尚未上线。

## 6. 重复掉落处理

- 同一次击败不会出现两个同名物品。
- 已经进入装备背包的唯一武器和防具不会在当前 Run 再次掉落。
- 同名武器成功结果转换为磨刀石；达到强化上限后转化为 1 XP。
- 同名防具成功结果转换为修理片；护甲已满时转化为 1 XP。
- 恢复品可以跨战斗重复获得并堆叠，但同一场最多出现一份同名恢复品。
- 新武器和防具进入背包，不强制自动替换当前装备。

所有转换都必须显示直接反馈，不能静默吞掉物品。

## 7. 地图与安全边界

- 湖中怪物只能在湖岸遭遇点、桥梁或湖心岛触发，不让玩家进入不可行走深水格战斗。
- 泥沼怪物只能在泥沼区域触发。
- 森林高草可以提高遭遇概率，但进入前必须有明显视觉提示。
- 区域首领放在可选地标，不堵塞篝火、课程门和主路径。
- 出生点和篝火石圈安全区内不生成任何生态怪物。
- 离开一个生态区域后，新的随机遭遇立即切换到当前区域怪物池。

## 8. MVP 范围

`v1.0` 已实现核心范围：

- 每层 2 至 3 个生态区域怪物池。
- 每个大型生态区域最多 1 个区域首领。
- 普通怪、小型精英、区域首领、固定精英和层主。
- 主题恢复品、武器、防具和明确拾取反馈。
- 稳定的种子掉落与重复物品转换。

## 9. 本次不做

- 不加入材料背包和合成。
- 不加入随机词条、装备品质颜色或装备耐久。
- 不加入水下战斗、游泳或复杂地形物理。
- 不让生态区域首领成为通关必需。
- 不让随机掉落解锁尚未学习的 SQL。
- 讨论确认前不修改当前游戏源码。

## 10. 验收标准

1. 湖泊、泥沼、森林等区域抽取各自的专属怪物。
2. 第一层只出现史莱姆族，后续楼层逐步升级到魔王军团。
3. 小型精英不受每层两只硬上限限制，但每个遭遇点只结算一次。
4. 每个大型生态区域最多一个区域首领。
5. 区域首领至少使用二阶复合题并保证主题掉落。
6. 普通怪和小型精英可以随机掉落装备，但楼层钥匙和必修奖励保持确定。
7. 刷新、死亡和休息不能重抽怪物或掉落。
8. 重复装备必须转换并给出清楚反馈。
9. 生态怪物不会进入出生点或篝火安全区。

## 11. 风险与取舍

- 每个区域都增加首领会让一层过长，因此只有足够大的生态区域才设置首领。
- 普通怪掉落种类过多会增加理解负担，MVP 中每个区域只保留少量直接效果。
- 小型精英无数量硬上限，需要通过有限遭遇点和逐层概率控制密度。
- 区域首领奖励过强会削弱层主奖励，因此区域首领提供构筑选择，层主仍提供楼层钥匙和结业奖励。
- 八层全部内容一次实现风险很高，正式开发时应先用第二层“湖泊 + 泥沼 + 森林”验证完整生态闭环。
