# MVP 2.1 / 第一、二层垂直切片发布检查表

> 状态：`LOCAL VALIDATED / PR PENDING`
>
> [PR #23](https://github.com/Kkkirito-123/select-from-dungeon/pull/23) 是八层 MVP 2.0 基线；
> 本表只验收在该基线上完成的第一、二层正式垂直切片。归档链接将在本轮统一 PR 创建后回填。

## 1. 目标与边界

- 目标：把第一、二层从八层兼容原型提升为可发布的内容样板——地点化地图、世界状态、抄写员、
  SQLite 剧情证据、名字回收图鉴、连续配乐与教学信息边界均可运行。
- 用户：SQL 初学者、面试复习者、博客访客、探索型玩家和项目维护者。
- MVP：第一、二层各有专属地图、剧情、音乐、素材和管理员世界状态；保留八层 47 组课程、
  真实 SQLite、战斗 / 成长 / 掉落 / 篝火 / 背包及第三至八层兼容表现。
- 不做：不接入 Agent、账号、后端、在线排行榜、隐藏地区、多结局、大型采样音源或新依赖。
- 发布方式：全部代码、内容、素材、文档与证据在一个功能分支收口，只创建一个垂直切片 PR。

## 2. 兼容与分发

- 当前包版本：`2.0.0`；本 PR 作为 `MVP 2.1 RC` 归档，正式标签另行决定。
- 当前 Run：使用 `select-from-dungeon:run:v11`；有效 v10 确定性迁移。
- 永久档案：使用 `select-from-dungeon:profile:v3`；有效 v1/v2 保留学习计数并补空身份集合。
- 引导状态：继续使用 `select-from-dungeon:onboarding:v1`。
- 新地图：`48×36 / generator v5`。
- 旧地图：`64×48 / generator v4` 继续读取；旧 Key 不删除。
- 新怪物编号：八层 `monsters.id` 连续为 `1–89`；旧稀疏编号在校验前确定性迁移全部运行引用，
  混合或未知编号拒绝恢复。
- 终局状态：第八层胜利原子提交 `mode = victory` 与 `campaign.status = completed`；
  旧终局异常组合在迁移链中确定性修复，其他矛盾组合拒绝恢复。
- 叙事状态：由现有楼层、必修进度、篝火、Boss 和结算状态派生，不新增联网或独立凭据存储。
- 构建产物：`dist/` 必须包含根 `LICENSE` 与 `ATTRIBUTIONS.md` 的逐字节副本。
- 部署、GitHub Release 和版本标签不在本 PR 自动执行。
