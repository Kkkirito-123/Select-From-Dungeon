## 1. 目标与边界

- 目标：冻结八层 SQL 肉鸽 MVP，并形成可追溯、可恢复、可静态托管的首个完整发布基线。
- 用户：SQL 初学者、面试复习者、博客访客和项目维护者。
- MVP：八层 47 个必修课程组、五阶段最终魔王、八套地图生态、篝火复活、背包/防具、
  受控随机遭遇与掉落、本地复盘、触控与 Reduced Motion。
- 不做：不新增玩法，不改课程顺序，不改存档结构，不接入 Agent/账号/后端，不部署，
  不创建 GitHub Release 或版本标签。

- 自动化：32 个 Vitest 文件、193 项测试（文件级串行，测试内样本量不变）；独立类型检查；
  8 个 Python 规则回归；12 项规则校验。

  `1280 / 1280`，控制台 0 警告、0 错误。

  `x=7, y=7, 376×830`，方向键为 `91×44`，动作按钮为 `62×89`，焦点落在关闭按钮，
  文档宽度 `390 / 390`。

  `史莱姆 #101`；执行 `SELECT name FROM monsters WHERE id = 101;` 后查询数 `0 → 1`、
  怪物生命 `12 → 6`，进入第二击任务。
